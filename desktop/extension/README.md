# 发送到清影（浏览器扩展）

Chrome、Edge、Firefox 扩展：把当前网页、链接或视频发送到电脑上的清影下载，接管浏览器的下载，并可把当前网站的登录 Cookie 同步给清影（用于 YouTube、Pornhub 等需要登录的网站）。

## 安装（开发者模式）

- Chrome / Edge：打开 `chrome://extensions`，开启“开发者模式”，点“加载已解压的扩展程序”，选择本目录。
- Firefox：打开 `about:debugging#/runtime/this-firefox`，点“临时载入附加组件”，选择本目录下的 `manifest.json`。

## 设置

1. 清影 → 设置 → 手机与浏览器扩展，开启服务。
2. 把“分享菜单”里的端口（地址中冒号后的数字）和访问令牌填到扩展的设置里，点“保存并测试”。
3. 第一次发送时，清影会弹窗请你确认配对。配对后才能同步 Cookie。

## 使用

- 工具栏按钮：发送当前页面、同步此网站的登录 Cookie。弹窗顶部显示与清影的连接状态。
- 自动同步（默认关闭）：在网站上勾选“登录状态变化时自动同步此网站”，以后该网站重新登录或 Cookie 更新时，扩展会自动同步给清影（每个网站最多 5 分钟一次）。只对列表里的网站生效，可在设置里移除。
- **接管浏览器下载**（默认关闭）：弹窗里勾选“接管浏览器下载”后，浏览器要下载的文件会交给清影，带上浏览器的 Referer、Cookie（只用于这一次下载，不进入清影的账号库）和文件名。清影里保存在“浏览器下载”分类，多段、断点续传、限速照常。
  - 范围：默认只接管常见的大文件类型（压缩包、安装包、镜像、音视频），也可以改成所有下载；已知大小小于“最小文件大小”（默认 1 MB）的不接管；可以设置只接管 / 不接管哪些网站（包含子域名）。点“接管下载设置”修改。
  - 临时绕过：按住 Alt 点击下载链接，或在弹窗里点“暂停 30 分钟”，这期间的下载留给浏览器。
  - 兜底：清影没有运行、没有配对或没接住时，下载会自动交还给浏览器，并弹出通知；弹窗里的“最近接管的下载”可以随时改用浏览器下载。
  - 限制：接管的下载由清影重新请求一遍，所以一次性链接、需要 POST 表单提交或依赖浏览器特殊状态的下载可能失败；`blob:`、`data:` 等地址无法交给清影，留给浏览器。
- **右键菜单**：对网页、链接、视频、音频、图片选“用清影下载”。指向压缩包、安装包、文档的链接按文件下载（带上来源页和 Cookie），其余交给清影解析。
- **视频嗅探**：打开视频网页后，扩展会记录页面加载过程中出现的视频流（m3u8、mpd）、视频 / 音频文件（小于 300 KB 的不记录）和图片（60 KB 以上），工具栏图标上显示数量。弹窗里按清晰度和大小排序，同一个地址去重，m3u8 / mpd 显示清晰度、时长和预估大小（带 ≈ 的是预估），直播和 DRM 加密的会标出来；可以勾选多项“发送所选”。发送时清影带着网页地址作为 Referer 去下载，适合内置解析器和 yt-dlp 都不支持的网站。**DRM 加密（Widevine、PlayReady、FairPlay、SAMPLE-AES）的内容无法下载**；普通 AES-128 加密的 m3u8 可以。需要 `webRequest` 权限，只在本机记录，换页面后清空，不会上传。

## 权限说明

| 权限 | 用途 |
|---|---|
| `downloads` | 接管浏览器下载：取消浏览器自己的下载、在清影没接住时交还给浏览器 |
| `cookies` | 同步登录 Cookie；接管下载和发送图片时带上这个地址的 Cookie |
| `webRequest` | 嗅探网页里的视频流和文件 |
| `contextMenus`、`notifications`、`storage`、`tabs`、`activeTab` | 右键菜单、通知、保存设置、读取当前标签页的地址和标题 |
| 所有网站 | 嗅探、读取 Cookie，以及一个只在你按住 Alt 点击时发送固定信号的小脚本（`bypass.js`，不读取页面内容） |

## 商店安装

商店审核通过后可直接从 Chrome 网上应用店、Edge 加载项或 Firefox 附加组件安装。上架步骤和材料见 [docs/release-guide/](../../docs/release-guide/README.md)；每个 Release 里的 `ClearClip-extension-<版本>.zip` 就是可上传的包。

## 安全

- 扩展只连接本机 `127.0.0.1`；Cookie 同步接口只接受本机、已配对设备的请求。
- Cookie 只在你点击“同步”时读取当前网站的 Cookie；接管下载时只读取被下载地址的 Cookie，发给本机的清影。不会读取其他网站，也不会发到任何外部服务器。
- 建议用浏览器的无痕窗口登录后同步，同步后关闭该窗口，避免网站因 Cookie 被两处使用而让登录失效。
