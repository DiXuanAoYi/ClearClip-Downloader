# 发送到清影（浏览器扩展）

Chrome、Edge、Firefox 扩展：把当前网页、链接或视频发送到电脑上的清影下载，接管浏览器的下载，把当前网站的登录 Cookie 同步给清影（用于 YouTube、Pornhub 等需要登录的网站），并提供一组页面小工具：视频悬浮下载按钮、批量选取、页面媒体总览、以图搜图、图片悬停放大、播放增强、稍后看、页面截图 / 摘录 / 保存、解除复制限制、视频摘要 / 总结 / 问答 / 思维导图。

## 安装（开发者模式）

- Chrome / Edge：打开 `chrome://extensions`，开启“开发者模式”，点“加载已解压的扩展程序”，选择本目录。
- Firefox：打开 `about:debugging#/runtime/this-firefox`，点“临时载入附加组件”，选择本目录下的 `manifest.json`。

## 设置

1. 清影 → 设置 → 手机与浏览器扩展，开启服务。
2. 把“分享菜单”里的端口（地址中冒号后的数字）和访问令牌填到扩展的设置里，点“保存并测试”。没填就点右键菜单时，扩展会直接打开设置页。
3. 第一次发送时，清影会弹窗请你确认配对。配对后才能同步 Cookie。

## 使用

- 工具栏按钮：发送当前页面、同步此网站的登录 Cookie。弹窗顶部显示与清影的连接状态。
- 自动同步（默认关闭）：在网站上勾选“登录状态变化时自动同步此网站”，以后该网站重新登录或 Cookie 更新时，扩展会自动同步给清影（每个网站最多 5 分钟一次）。只对列表里的网站生效，可在设置里移除。
- **接管浏览器下载**（默认关闭）：弹窗里勾选“接管浏览器下载”后，浏览器要下载的文件会交给清影，带上浏览器的 Referer、Cookie（只用于这一次下载，不进入清影的账号库）和文件名。清影里保存在“浏览器下载”分类，多段、断点续传、限速照常。
  - 范围：默认只接管常见的大文件类型（压缩包、安装包、镜像、音视频），也可以改成所有下载；已知大小小于“最小文件大小”（默认 1 MB）的不接管；可以设置只接管 / 不接管哪些网站（包含子域名）。点“接管下载设置”修改。
  - 临时绕过：按住 Alt 点击下载链接，或在弹窗里点“暂停 30 分钟”，这期间的下载留给浏览器。
  - 兜底：清影没有运行、没有配对或没接住时，下载会自动交还给浏览器，并弹出通知；弹窗里的“最近接管的下载”可以随时改用浏览器下载。
  - 限制：接管的下载由清影重新请求一遍，所以一次性链接、需要 POST 表单提交或依赖浏览器特殊状态的下载可能失败；`blob:`、`data:` 等地址无法交给清影，留给浏览器。
- **右键菜单**：对网页、链接、视频、音频、图片选“用清影下载”。指向压缩包、安装包、文档的链接按文件下载（带上来源页和 Cookie），其余交给清影解析。 点击后清影主窗口会回到前台并给出提示，扩展图标上短暂显示 ✓（已发送）或 !（失败），弹窗的“最近发送”里也有记录。
- **视频嗅探**：打开视频网页后，扩展会记录页面加载过程中出现的视频流（m3u8、mpd）、视频 / 音频文件（小于 300 KB 的不记录）和图片（60 KB 以上），工具栏图标上显示数量。弹窗里按清晰度和大小排序，同一个地址去重，m3u8 / mpd 显示清晰度、时长和预估大小（带 ≈ 的是预估），直播和 DRM 加密的会标出来；可以勾选多项“发送所选”。发送时清影带着网页地址作为 Referer 去下载，适合内置解析器和 yt-dlp 都不支持的网站。**DRM 加密（Widevine、PlayReady、FairPlay、SAMPLE-AES）的内容无法下载**；普通 AES-128 加密的 m3u8 可以。需要 `webRequest` 权限，只在本机记录，换页面后清空，不会上传。

## 页面小工具（1.4 – 1.10）

设置页的“功能开关”里可以逐项开关。**需要在每个网页里常驻运行的功能默认关闭**（标着“常驻”）；倍速、记住倍速、快进快退这三项默认开启，只在页面里真的有视频 / 音频时才初始化。“按需”的功能只在你点了之后才向页面注入脚本，用完即走。每个常驻功能都可以在设置里按网站关闭。

| 功能 | 怎么用 | 说明 |
|---|---|---|
| 链接清理 | 弹窗“工具”标签；右键“复制干净的链接”；发送前自动清理 | 去掉 `utm_*`、`fbclid` 等追踪参数，还原 `?url=` 跳转链接；追踪参数名单可自己加；弹窗里用删除线标出被去掉的参数 |
| 二维码 | 弹窗“工具”标签；右键“用二维码在手机上打开此页…” | 本地生成，不联网；也可以“发到手机盒子” |
| 下载进度 | 弹窗“下载”标签；图标角标；完成通知 | 每秒刷新，暂停 / 继续 / 在文件夹中显示；图标角标显示进行中的数量 |
| 自动同步 Cookie | 弹窗里勾选“登录状态变化时自动同步此网站”；清影提示“需要登录”时扩展询问 | 只对列表里的网站生效，每个网站最多 5 分钟一次；确认后清影自动重试失败的任务 |
| 视频悬浮下载按钮（常驻） | 鼠标移到视频上出现按钮，可选清晰度 | 在 iframe 和打开的 Shadow DOM 里的视频也能识别 |
| 批量选取 / 页面媒体总览（按需） | 弹窗“发现”标签，或右键菜单 | 批量选取：在页面上点选图片、视频、链接，一起发送；总览：把页面里的图片、视频、音频按网格列出，可按尺寸过滤、勾选后发送 / 复制地址 / 以图搜图 |
| 以图搜图（按需） | 在图片上右键 | 默认 Google、Bing、Yandex、TinEye、百度、搜狗，可在设置里增减、改顺序、加自定义地址（用 `{url}` 代表图片地址）；只有你点了才把图片地址交给你选的搜索引擎；“上传本地图片…”只支持 TinEye / Bing / Google，目前没有在真实站点上验证过 |
| 图片悬停放大 / 画廊（常驻） | 鼠标悬停图片；按住 Alt 锁定；`+` `-` 缩放，`R` 旋转，`S` 保存，`G` 打开页面画廊 | 按“取原图”规则找大图：页面线索（链接地址、`data-original`、`srcset`）→ 内置站点规则 → 你自己的规则（每行 `匹配正则 => 替换`）；候选地址会先试加载，最多试 4 个 |
| 播放增强（常驻） | 鼠标移到视频上出现控制条；快捷键见设置 | 倍速 0.1×–16×（默认 `S` 减速、`D` 加速、`R` 复位），网站把倍速改回去时自动恢复，自己在网站菜单里改的则跟随；记住每个网站的倍速；`Z` / `X` 快退 / 快进（默认 10 秒）；截图（`V`）、画中画（`P`）、A–B 循环（`[` `]` `\`）、逐帧（`,` `.`）；跳过片头片尾（按网站设置秒数）、音量增益 100–400%、镜像 / 旋转 / 亮度 / 对比度 / 饱和度 / 填充。快捷键可自定义，设置里会检测冲突；在输入框里打字时不会触发 |
| 稍后看 | 右键“稍后看”；弹窗“稍后看”标签 | 同一链接自动去重（忽略 `#` 后面的部分）；列表保存在扩展本地，离线也能用，最多 300 条；可以一键下载、标记已看、删除 |
| 页面保存与摘录（按需） | 弹窗“工具”标签的“页面保存”；右键“页面保存”；选中文字后右键“摘录选中文字到清影” | 截图（可见区域 / 选取区域 / 整页）、另存为 PDF、保存为 Markdown（先预览、可修改）；摘录把选中文字 + 标题 + 来源存成清影里的文字便签 |
| 视频摘要 / 总结（按需，**1.10**） | 弹窗“发现”标签的“视频摘要 / 总结”；右键“视频摘要 / 总结…”；选中文字后右键“总结选中的文字…”；**Alt+Shift+S** | 读取 YouTube / 哔哩哔哩 / 播放器字幕轨，在页面右侧开侧栏：摘要、章节、文稿（搜索 / 翻译 / 导出）、思维导图（SVG / PNG）、问答（回答里的时间可点）、学习卡片（Anki）、金句、改写成社交文案、导出 Markdown / Obsidian / 清影便签。**需要在清影“设置 → AI”里填好模型**；文稿只发给本机清影，由清影调用你配置的模型。详见 [docs/video-summary.md](../../docs/video-summary.md) |
| 解除复制 / 右键限制（常驻 · 页面环境） | 弹窗“工具”标签里给当前网站打开开关 | **只对你开启过的网站生效**（高级里有“所有网站”，不建议）；见下面“解除限制的说明” |

已知限制：

- 视频摘要：没有字幕的视频点“用清影转写”，由清影取音频并在本机语音识别（需要 yt-dlp、ffmpeg 和语音转文字设置，较慢）；YouTube / 哔哩哔哩的页面结构会变，读取字幕可能失效，这时可导入字幕文件或粘贴文字稿；嵌在 iframe 里的播放器读不到；摘要质量取决于你配置的模型。

- 播放增强的**音量增益**一旦接入就不能撤销（浏览器限制，`createMediaElementSource` 不能拆）；跨域且没有 CORS 的视频放大后会没有声音，所以扩展会事先拒绝，并提示刷新页面恢复。
- 视频截图遇到受保护（跨域、没有 CORS）的视频会改用浏览器对可见区域的截图再裁剪；DRM 视频黑屏是浏览器的限制。
- 整页截图：每屏之间要等约 0.65 秒（Chrome 限制 `captureVisibleTab` 每秒最多 2 次），固定在顶部的元素只保留第一屏，超长页面分成几张图（单张最高 16384 像素），最多截 60000 像素。页面内部有自己的滚动区域（很多网页应用）时只能截到可见部分，请改用“选取区域”。
- “另存为 PDF”：Firefox 直接保存；Chrome / Edge 会打开打印对话框，目标选“另存为 PDF”。
- Markdown 的正文提取是尽力而为，所以先给预览、可以修改；想只保存一部分，先在页面里选中那部分再保存。
- 稍后看目前只存在扩展本地，没有同步到清影的“收件箱”（避免两处各有一份状态）。
- 在页面里无法使用的位置：浏览器内置页面、扩展商店页面。

### 解除限制的说明

很多网页用脚本或样式禁止选中文字、复制、右键。开启后，扩展在你指定的网站里：

- 让文字可以选中（覆盖 `user-select: none`）；
- 对 `copy`、`cut`、`contextmenu`、`selectstart`、`dragstart` 事件，以及 Ctrl/⌘ + A / C / X，网站调用 `preventDefault()` 或返回 `false` 不再生效，网站追加“版权小尾巴”的做法也因此失效（浏览器会复制你选中的原文）；
- 第一次真的拦住网站的限制时，在页面角落显示一条提示，带“撤销”按钮。

它**只解除浏览器端的限制**：不绕过付费墙和登录墙，不提取图片或 canvas 里的文字，不破解 DRM。可能影响拖拽排序、在线文档、网页游戏等依赖这些事件的页面，所以默认只对你开启过的网站生效，出问题时在弹窗里关掉这个网站即可。这个脚本运行在页面自己的环境（`world: "MAIN"`，Chrome 111+ / Firefox 128+），只会被注册到你开启过的网站，不读取页面内容、不联网、没有任何扩展接口。

## 权限说明

| 权限 | 用途 |
|---|---|
| `downloads` | 接管浏览器下载：取消浏览器自己的下载、在清影没接住时交还给浏览器 |
| `cookies` | 同步登录 Cookie；接管下载和发送图片时带上这个地址的 Cookie |
| `webRequest` | 嗅探网页里的视频流和文件 |
| `scripting` | 1.4 新增。按需往页面注入脚本（总览、批量选取、截图、Markdown、复制链接），以及按你开启的功能注册 / 注销常驻脚本 |
| `alarms` | 1.4 新增。每 30 秒检查一次清影的下载进度和“需要登录”提示（只在清影已配置时） |
| `contextMenus`、`notifications`、`storage`、`tabs`、`activeTab` | 右键菜单、通知、保存设置、读取当前标签页的地址和标题；整页 / 选区截图用 `tabs.captureVisibleTab`，只在你点了截图之后调用 |
| 所有网站 | 嗅探、读取 Cookie、按需注入脚本，以及一个只在你按住 Alt 点击时发送固定信号的小脚本（`bypass.js`，不读取页面内容）。常驻脚本只在你开启了对应功能后才注册；“解除限制”只注册到你开启过的网站 |

## 商店安装

商店审核通过后可直接从 Chrome 网上应用店、Edge 加载项或 Firefox 附加组件安装。上架步骤和材料见 [docs/release-guide/](../../docs/release-guide/README.md)；每个 Release 里的 `ClearClip-extension-<版本>.zip` 就是可上传的包。

## 安全

- 扩展只连接本机 `127.0.0.1`；Cookie 同步接口只接受本机、已配对设备的请求。以图搜图只在你点了之后才打开搜索引擎的网页，并把图片地址放进网址里。
- Cookie 只在你点击“同步”时读取当前网站的 Cookie；接管下载时只读取被下载地址的 Cookie，发给本机的清影。不会读取其他网站，也不会发到任何外部服务器。
- 建议用浏览器的无痕窗口登录后同步，同步后关闭该窗口，避免网站因 Cookie 被两处使用而让登录失效。
