# 字幕、弹幕、片段与章节

## 字幕与弹幕

解析后，“字幕与弹幕”区域会列出能下载的字幕轨：

| 来源 | 内容 | 说明 |
| --- | --- | --- |
| YouTube 等（yt-dlp） | 人工上传的字幕 | 每种语言一个，偏好语言排在前面 |
| YouTube | 自动生成字幕、偏好语言的自动翻译 | 原语言的自动字幕（标注“机器生成”）和你的偏好语言的机器翻译（标注“机器翻译”）；该语言已有人工字幕时不再列出自动的 |
| B站 | CC 字幕、AI 字幕 | **获取字幕需要登录 B站**，未登录时列表里没有；AI 字幕标注“AI 生成” |
| B站 | 弹幕 | 默认转成 ASS，播放器可以直接显示滚动弹幕 |

### 偏好语言

“设置 → 解析 → 字幕与弹幕”里的**偏好语言**（默认 `zh, en`，靠前的优先）决定：

- 字幕在列表里的排序，以及“按偏好语言选择”按钮选中哪些；
- 自动翻译哪些语言会被列出；
- 下载视频时自动带上哪些字幕（见下一节）。

`zh` 同时匹配简体、繁体等变体（`zh-Hans`、`zh-TW`……）。每个偏好语言只选一条，人工字幕优先于自动生成和 AI 字幕。

### 处理方式

选中字幕后可以选择：

- **单独保存为文件**：和视频放在同一个文件夹，文件名与视频相同再加语言（如 `视频.zh-Hans.srt`），播放器会自动加载。
- **内嵌到视频**：作为可切换的字幕轨写进视频文件，不重新编码，很快。MP4 只能内嵌文字字幕，不能内嵌 ASS 弹幕（会被跳过，提示在任务里）；MKV 都可以。
- **烧录进画面**：字幕直接画进画面，任何播放器都能看到。需要重新编码视频，耗时较长；多种语言会叠在一起，所以只烧录选中的第一条文字字幕，弹幕可以同时烧录。需要带 libass 的 ffmpeg（“设置 → 组件”里安装的版本支持）。

字幕处理失败时视频本身仍然会保存，原因显示在下载队列里该任务的黄色提示中。

“设置 → 解析 → 字幕与弹幕”里的**下载视频时同时处理字幕**可以对剪贴板自动下载、播放列表和订阅生效（默认“不处理”）。

### 格式转换

- **VTT → SRT**（默认开启）：SRT 是播放器和剪辑软件通用的格式。YouTube 自动字幕是“滚动”的（后一条会重复前一条的最后几行），转换时会整理掉重复。
- **B站 CC 的 JSON → SRT**：总是转换，JSON 无法直接播放。
- **B站弹幕 XML → ASS**（默认开启）：滚动、顶部、底部弹幕分行排布不重叠，没有空行时丢弃该条；高级弹幕（定位、代码）不支持。

## 只下载一段

勾选“只下载一段”，填写开始和结束时间（`83`、`1:23`、`01:02:03` 都可以，结束留空表示到结尾）。

- 默认**不重新编码**：很快，但开头会落在前一个关键帧上，可能比设置的时间早一两秒；
- 勾选“精确剪切”会重新编码，起点精确到帧，较慢。

同时选中的字幕和弹幕也会按这个时间段裁剪，并把时间平移到从 0 开始，和裁剪后的视频对得上。

目前是下载完整视频后再裁剪，不会节省下载流量。

## 章节

视频带章节信息（YouTube 等）时，会列出章节：

- **只下载这一章**：把这一章的起止时间填进“只下载一段”；
- **同时把每个章节另存为单独的文件**：完整视频保留，另外在“视频名 章节”文件夹里生成 `01 开场.mp4`、`02 正文.mp4` ……（不重新编码）。可以和“只下载一段”一起用，章节时间会自动跟着平移。

## 播放列表

解析出播放列表（YouTube 播放列表、合集等）后：

- 每个条目显示封面和时长，之前下载过的标“已下载”（按作品 ID 或原链接判断）；
- 可以搜索标题、全选 / 反选、**只选没下载过的**、按序号选中一个范围（第 N 到第 M 条）、隐藏已下载的；
- “设置 → 下载 → 跳过已下载过的内容”开启时，默认只选没下载过的，省去逐条解析的时间。

## 下载后检查

“设置 → 下载 → 完成后 → 下载后检查文件”（默认开启，需要 ffmpeg）：每个视频或音频下载完成后用 ffmpeg 检查能否正常读取。

- 读不出音频或视频（文件损坏、被截断）：自动清理后**从头重新下载一次**；再失败则任务标为失败并给出原因，可以手动重试。
- 文件时长比网站标注的短很多：只在任务里提示“可能不完整”，不判失败（跳过广告的 m3u8、网站标注的时长不准都会造成差异）。
