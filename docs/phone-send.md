# 手机发链接到电脑

在清影的“设置 → 手机与浏览器扩展”中开启后，手机和电脑连同一个 Wi-Fi（或同一局域网），就可以把手机上复制的链接发到电脑下载。链接只在局域网内传输，不经过任何外部服务器。

## 方式一：扫码打开网页

1. 电脑上开启“手机发链接到电脑”，界面会显示二维码。
2. 用手机相机或微信扫一扫打开网页（建议“添加到主屏幕”，下次直接打开）。
3. 长按输入框粘贴分享文案或链接，点“发送到电脑”。
4. 第一次从这台手机发送时，电脑上会弹窗请你确认配对，点“允许”。
5. 网页下方会显示发送记录和下载状态（解析中 / 下载中 / 已完成 / 失败）。

> 网页是局域网里的 HTTP 页面，浏览器不允许它直接读取剪贴板，所以需要手动长按粘贴。下面的分享菜单方式没有这个限制。

## 方式二：加入手机分享菜单

在电脑上的“设置 → 手机与浏览器扩展 → 分享菜单”中可以复制**接口地址**和**访问令牌**（X-Token）。

### iPhone / iPad：快捷指令

1. 打开“快捷指令” App，新建快捷指令，命名为“发送到清影”。
2. 点下方的 ⓘ（详细信息），打开“在共享表单中显示”，接收类型选“URL”和“文本”。
3. 添加操作“获取 URL 内容”：
   - URL：填电脑上复制的接口地址，例如 `http://192.168.1.10:51234/api/send`
   - 方法：`POST`
   - 头部：添加 `X-Token`，值为电脑上复制的访问令牌
   - 请求体：`JSON`，添加三个字段：
     - `text`：选择变量“快捷指令输入”
     - `device`：`iphone-shortcut`
     - `name`：`我的 iPhone`
4. （可选）再添加“显示通知”，内容选“获取 URL 内容”的结果。
5. 在抖音、B站等 App 里点“分享 → 更多 / 复制链接旁的 …”，选择“发送到清影”。

第一次发送时电脑上会请求配对，允许后以后都会直接开始下载。

### Android：HTTP Shortcuts

1. 安装开源应用 [HTTP Shortcuts](https://http-shortcuts.rmy.ch/)。
2. 新建快捷方式，类型选“普通 HTTP 请求”：
   - 方法：`POST`，URL：电脑上复制的接口地址
   - 请求头：`X-Token` = 访问令牌
   - 请求体：类型选“自定义文本”，Content-Type 填 `application/json`，内容：
     ```json
     {"text": "{{shared_text}}", "device": "android-shortcut", "name": "我的 Android"}
     ```
     其中 `shared_text` 是在“变量”里新建的“分享的文本”类型变量。
3. 在快捷方式的“触发与执行”设置中打开“出现在分享菜单”。
4. 在 App 里分享时选择这个快捷方式即可。

也可以直接发送纯文本正文（`Content-Type: text/plain`），清影会从中提取链接；这种情况下设备按手机的 IP 地址区分。

## 记录与重试

所有发来的链接都会记录在电脑上的“媒体库 → 收到的链接”里（重启后仍在）：

- 按来源（手机 / 浏览器扩展 / 剪贴板 / 手动粘贴）和状态筛选，可搜索；
- 失败的链接可以一键重试，需要登录的会显示“登录 XX”按钮，登录保存后自动重试；
- “需要确认”的链接（“识别后自动下载”关闭时）可以直接点“下载”；播放列表需要在解析页选择条目；
- 新设备配对前发来的链接，允许配对后会继续处理；即使在电脑上还没点之前就重启了程序，下次启动仍会弹出配对确认；
- 保留天数和最多条数可在“设置 → 解析 → 收到的链接”调整。

## 接口说明

| 接口 | 说明 |
| --- | --- |
| `GET /?t=令牌` | 手机网页 |
| `POST /api/send` | 发送链接。请求头 `X-Token`，正文 `{"text", "device", "name"}`，返回 `{"id", "state"}` |
| `GET /api/status?device=设备ID` | 该设备最近 20 条发送记录及状态 |

`state` 取值：`pending_pair`（等待电脑确认配对）、`rejected`、`resolving`、`confirm`（“识别后自动下载”关闭时，需要在电脑上确认）、`playlist`（是列表，需要在电脑上选择条目）、`queued`、`downloading`、`done`、`failed`、`ignored`（在电脑上忽略了）。

## 安全

- 默认关闭；只接受局域网和本机地址的请求，来自公网的连接直接断开。
- 二维码和快捷指令里带随机访问令牌；新设备第一次发送需要在电脑上确认配对，可在设置里撤销已配对的设备，或“重新生成令牌”让旧的二维码和快捷指令全部失效。
- 网页只能发送链接、查看自己发送的任务状态，不能浏览或下载电脑上的文件。
- 限制请求大小（16 KB）和频率（每个地址每分钟 60 次）；关闭功能时立即停止服务。
- 第一次开启时 Windows 可能弹出防火墙提示，请允许“专用网络”访问；公共网络不建议开启。
- 手机和电脑不在同一网络时无法使用（需要服务器中转，暂不支持）。
