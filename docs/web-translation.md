# 网页翻译与多语种互译（扩展）

参考了「沉浸式翻译」等翻译插件的做法（双语对照、只翻看得见的、动态内容、悬停 / 划词 / 输入框翻译、站点名单），做成扩展里的一项功能；**默认由清影调用你在“设置 → AI”里配置的大模型翻译**，也可以改用免费的谷歌翻译。

## 怎么用

| 方式 | 操作 |
|---|---|
| 翻译整页 | 快捷键 **Alt+A**；弹窗“工具”里的“翻译本页”；右键菜单“翻译本页 / 还原” |
| 翻译鼠标指着的一段 | **单击一下 Ctrl**（可改成 Alt / Shift 或关闭）；再单击一次还原这一段。Ctrl+C 之类组合键不会触发 |
| 翻译选中的文字 | 选中文字后点旁边出现的“译”，或右键“翻译选中的文字”；弹出译文卡片，可复制 |
| 输入框里写外语 | 在输入框 / 文本域里 **连按三次空格**，把里面的内容换成“输入框语言”（默认英文） |
| 自动翻译某些网站 | 弹窗 → 设置 → 网页翻译 → “自动翻译的网站”填域名（含子域名）；“永远不翻译的网站”优先于前者；本来就是目标语言的页面不会翻 |

## 效果

- **双语对照**（默认）：原文保持原样，译文紧跟在原文所在段落后面；样式可选淡色 / 下划线 / 高亮 / 无。
- **只显示译文**：藏起原文，只留译文；切回双语或再按 Alt+A 即还原。
- 只翻译看得见（和快要看见）的段落，滚到哪翻到哪；页面后来加载的内容（评论、无限滚动）也会翻。
- 不翻：代码块、输入框、`translate="no"` / `notranslate` 的内容、纯数字符号、网址邮箱，以及本来就是目标语言的段落。
- 同一句话在本机缓存（最多约 3000 条），重复内容不再请求；设置里可清空。

## 语言

36 种常见语言可互译（简体 / 繁体中文、英、日、韩、法、德、西、葡、俄、阿拉伯、印地、泰、越南、印尼、土耳其……），也可以直接填写别的语言名。

- 网页翻译：弹窗“工具”和设置里选“目标语言”。
- 视频摘要面板：摘要页可选“输出语言”；文稿页的“翻译”可选目标语言，选“自动”时中文译成英文、其他译成中文。

## 两个引擎

| 引擎 | 说明 |
|---|---|
| 清影（大模型，默认） | 文字只发给你电脑上的清影（127.0.0.1），由清影调用你在“设置 → AI”配置的模型（可以是本地 Ollama）。需要清影在运行。 |
| 谷歌翻译（免费，需自己开启） | 扩展直接请求 `translate.googleapis.com`，**页面文字会发给谷歌**，所以默认不用，选它时设置里有明确提示。不需要运行清影；请求过多可能被限流（HTTP 429）。 |

## 数据流与隐私

- 清影引擎：`网页文字 → 扩展后台 → 127.0.0.1 → 清影 → 你配置的模型`。
- 谷歌引擎：`网页文字 → 扩展后台 → translate.googleapis.com`。
- 只有你开启整页翻译 / 在名单里的网站 / 点了悬停或划词时才会读取并发送页面文字；输入框翻译只在你连按三次空格时发送那一个输入框的内容。
- 译文缓存只在浏览器本地（`storage.local`）。

## 应用端接口

`POST /api/v1/ai/run`，`kind: "webtrans"`，参数 `lang`（目标语言名）、`lines: [{t, text}]`；结果 `{lines:[{t,text}], failed}`，条数与顺序一一对应；已经是目标语言的内容原样返回。

## 已知限制

- 没有在真实的各类网站上逐一验证；个别用 Shadow DOM 渲染正文、或把文字拆成大量小标签的页面可能翻不全或断句不理想。
- “只显示译文”会临时给原文包一层标记，页面脚本若同时修改这些节点可能出现冲突，再按一次 Alt+A 可还原。
- 暂不支持 PDF / EPUB、视频播放器上的双语字幕叠加、图片文字翻译。
