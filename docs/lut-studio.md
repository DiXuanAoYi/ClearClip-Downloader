# LUT 工作室

LUT 是一张“颜色换算表”：输入一种颜色，查表得到调整后的颜色，所以一张表就能把一整套调色（偏暖、青橙电影感、褪色胶片……）原样用到任何画面上。工作室帮你**边看效果边调，调好后生成 `.cube` 文件**，可以用在清影的视频规整里，也可以导入剪映、DaVinci Resolve、Premiere、OBS 等支持 3D LUT 的软件。

入口：工具箱 → LUT 工作室。所有处理都在本机完成，需要 ffmpeg（在“设置 → 组件”里安装）来读取图片和视频帧。

## 三种来源，可以任意组合

1. **基础调色**：曝光、黑场 / 白场、中间调、对比度、阴影 / 高光、色温 / 色调、饱和度、自然饱和度、色相偏移、分色调（给暗部和亮部各染一种颜色）、整体强度。每一项都有“↺”重置；也有几个一键风格（暖调、冷调、青橙电影感、褪色胶片、鲜艳通透、清新明亮、黑白高反差），套用后只是把滑块摆到一组位置，还能接着微调。
2. **基底 LUT**：添加别人做好的 `.cube`（3D LUT），先套用它，再在它的基础上调。可以添加多张，按列表顺序叠加，各自有强度，能上下移动。
3. **参考图匹配**：选一张色调想要的图片，让示例图片的**明暗分布**和**整体色彩**（偏色、饱和度）向它靠拢，两项强度分别可调。

处理顺序是：基底 LUT → 基础调色 → 参考图匹配，最后在 N×N×N 个格点上取值写成 `.cube`。

## 怎么用

1. 先选一张**示例图片**（png / jpg / webp 等），或者一个视频，再填视频里的时间点，取那一帧。示例图片用来预览，也是参考图匹配的起点；选一张有代表性的画面，最好既有亮部又有暗部、有人物肤色的。
2. 页面上方并排显示“原图”和“调整后”，往下拖滑块时这一块会固定在上面，效果实时更新。预览用的就是即将生成的 LUT，所以看到的就是 `.cube` 文件的真实效果。
3. 想在别人的 LUT 上继续调：在“基底 LUT”里添加；想学一张图的色调：在“参考图匹配”里选它。
4. 调好后，填 LUT 名称、选精细度（17 小而快、33 推荐、65 精细但文件大），点“保存为 .cube…”。保存好之后，可以点“用于视频规整”直接带到视频规整里使用。
5. 也可以点“导出调整后的图片…”，把同样的效果套在示例图片（或视频的那一帧）的原图上，保存成 png / jpg / webp。

## 它是怎么算的

- **曝光**在线性光里调（先把 sRGB 编码的数值还原成线性光，乘上 2 的几次方，再编码回去），所以提亮不会发灰；**对比度**用以中灰为轴的 S 曲线，黑和白不动；**阴影 / 高光**按亮度加权，只作用在暗部或亮部，且在灰阶上保持单调（不会出现明暗反转）。
- **色温 / 色调**在线性光里调各通道的增益；**饱和度**围绕亮度缩放；**自然饱和度**对不够鲜艳的颜色加得多、对已经很艳的颜色加得少，肤色不容易过头；**分色调**只改颜色，不改明暗。
- **参考图匹配**：在 CIE Lab 色彩空间里做。明暗用亮度直方图匹配（分位数配对、平滑、单调，不会产生色带或反相）；色彩用 Reinhard 的均值 / 方差迁移作用在 a、b 通道上，缩放有上限，极端的暗部和亮部会减弱，避免把黑和白染色。匹配拟合在“已经叠好基底 LUT 和基础调色”的示例图片上，所以和上面的滑块可以同时用。
- **插值**：预览和 ffmpeg 的 `lut3d` 都用四面体插值，所以“预览里看到的”和“视频规整里用这张 LUT 的结果”一致；程序里有测试对着真实的 ffmpeg 输出比较。

## 限制

- 生成的 LUT 面向**普通的 Rec.709 / sRGB 画面**，也就是手机、相机直出和平台下载的常见视频与图片。S-Log、V-Log、C-Log 之类的 Log 素材和 HDR 素材，需要先转换色彩空间再用，直接套用效果不对。
- 只支持 **3D LUT**（`.cube` 里写着 `LUT_3D_SIZE`）。1D LUT 会提示不支持；`DOMAIN_MIN` / `DOMAIN_MAX` 会按文件里写的处理。
- 参考图匹配得到的是**整体的色调倾向**，不会把参考图的内容搬过来，也不能让某个局部变成另一种颜色（比如只把天空变蓝）。要局部调色请用剪辑软件的蒙版。
- 示例图片很小时（缩到最长边 720 像素预览）看到的细节有限，但生成的 LUT 与图片大小无关。
- 一张 LUT 的所有调整只依赖像素自己的颜色，所以没有锐化、降噪、暗角、颗粒这类需要看周围像素的效果。

## 和视频规整的关系

[视频规整](video-normalize.md)里的“LUT 调色”一项可以直接选用这里生成的 `.cube`，并能调强度。LUT 在 SDR 画面上应用；素材是 HDR 时先转 SDR 再套 LUT。
