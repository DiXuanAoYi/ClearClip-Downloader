# 隐私政策

适用于：清影 ClearClip 桌面版，以及浏览器扩展“发送到清影 ClearClip”。最后更新：2026 年 10 月（扩展 1.10.0：新增视频摘要 / 总结；此前 1.9.0：下载进度、页面小工具、播放增强、稍后看、页面保存与摘录、解除复制限制）。

## 一句话

清影和它的浏览器扩展**不收集、不上传、不出售任何用户数据**。所有数据都只保存在你自己的电脑上，扩展只和你电脑上运行的清影通信。

## 浏览器扩展

扩展只在你主动操作（或你主动开启的功能）时工作，并且**只连接本机地址 `127.0.0.1`**，不会连接任何外部服务器，也不包含统计、广告或远程代码。向网站发出的请求只有“发现视频”时取回页面里已经出现的 m3u8 / mpd 清单文件（用来显示时长和清晰度），与页面自己的请求一致，不会发给网站以外的任何地方。另外，以图搜图只在你右键点击后，打开你选的搜索引擎网页，并把那张图片的地址放进网址里。

| 功能 | 使用的数据 | 去向 |
| --- | --- | --- |
| 发送当前页面 / 链接 / 视频 | 你选择发送的网址、页面标题 | 发送到你电脑上运行的清影，用于解析和下载 |
| 发现视频（随扩展运行，没有单独开关） | 页面加载过程中出现的视频流、视频、音频、图片的地址、类型、大小，以及所在标签页的网址和标题 | 只保存在浏览器的会话存储里，换页面或重启浏览器后清空；你点“发送”时，才把所选地址和页面网址（作为来源页）发给本机的清影 |
| 接管浏览器下载（默认关闭，需手动开启） | 浏览器新开始的下载的地址、来源页、文件名、大小，以及该下载地址的 Cookie | 只发送到你电脑上运行的清影；Cookie 只用于这一次下载，不进入清影的账号库。扩展会取消浏览器自己的下载并把它从浏览器的下载列表里移除；清影没接住时再交还给浏览器 |
| 同步此网站的登录 Cookie | 当前网站的 Cookie（你点击“同步”时，或你开启了该网站的“自动同步”后，在该网站登录状态变化时） | 只发送到你电脑上运行的清影，用于下载需要登录的内容；不会发给任何其他地址 |
| 下载进度与“需要登录”提示 | 从你电脑上的清影读取下载任务的名称、进度、状态，以及“需要登录”的网站 | 只在扩展和清影之间（127.0.0.1）传递，用于图标角标、弹窗里的下载列表和询问是否同步 Cookie；不保存历史 |
| 页面小工具（视频悬浮下载按钮、图片悬停放大、播放增强，默认关闭或仅在页面有视频时初始化） | 页面里的视频 / 图片元素的地址，以及你的倍速、快捷键等设置 | 在页面里本地处理；只有你点“下载 / 发送”时才把对应地址发到本机的清影。倍速按网站记在本地 |
| 页面媒体总览、批量选取、以图搜图 | 你选择的图片、视频、链接地址 | 发送到本机的清影；以图搜图时，只有你点击的那一张图片的地址会交给你选的搜索引擎（默认 Google、Bing、Yandex、TinEye、百度、搜狗，可修改） |
| 稍后看 | 你保存的页面网址和标题（最多 300 条） | 只保存在浏览器的本地扩展存储中；不上传，不同步到云端；你点“下载”才发给本机的清影 |
| 页面保存与摘录（截图、PDF、Markdown、摘录文字） | 你点击后，当前标签页的可见画面、网页正文或你选中的文字 | 截图和 Markdown 只保存到你的下载文件夹；“摘录”和“发送为便签”只发送到本机的清影；不上传 |
| 视频摘要 / 总结（按需，用户点击后才注入） | 只读取当前页面里的字幕（YouTube / 哔哩哔哩的字幕接口、播放器的字幕轨）、你选中的文字或页面正文，以及视频标题 | 这些文字只发送给你电脑上运行的清影（127.0.0.1）；由清影调用你在“设置 → AI”里配置的模型接口。扩展自己不联网请求任何第三方，模型密钥不进入扩展。生成结果缓存在扩展本地存储（最多 40 条），可随时清除 |
| 解除复制 / 右键限制（默认关闭，需手动为网站开启） | 不读取页面内容。脚本只让页面的复制、右键、选择文字等操作不被网站拦截 | 脚本只被注册到你开启过的网站；运行在页面自己的环境里，不联网，不使用扩展接口，不存储任何数据 |
| 保存设置和记录 | 清影的端口、访问令牌、设备编号、自动同步的网站列表、接管下载的设置，功能开关、按网站的规则、快捷键、稍后看列表、倍速记忆，以及最近 20 条接管记录（网址、文件名、是否成功） | 保存在浏览器的本地扩展存储中，不会同步到云端；卸载扩展即删除 |

- 扩展**不保存浏览记录**，不监视你访问了哪些网页，不读取页面内容（页面里的文字、表单、输入）。页面里的 `bypass.js` 只在你按住 Alt 点击时发出一个固定信号，不读取任何内容。你在设置里开启的常驻功能（悬浮按钮、图片放大、播放增强、解除限制）只处理它们自己要操作的元素，不读取页面里的文字、表单或输入，也不把页面内容发送到任何地方。
- 接管下载只处理符合你设置的类型、大小和网站范围的下载；只读取这一个下载的信息，不枚举、不读取其他下载记录，也不读取下载文件的内容。关闭该功能后，扩展不再监听下载。按住 Alt 点击链接，或在弹窗里“暂停 30 分钟”，可以临时让下载留给浏览器。
- Cookie 只在“同步”时读取当前网站的，接管下载 / 发送文件时只读取被下载地址的，不读取其他网站的。自动同步默认关闭，且只对你在列表里勾选过的网站生效，每个网站最多每 5 分钟一次。
- 申请的权限及用途：
  - `downloads`：接管浏览器下载（取消浏览器自己的下载并移除其记录、清影没接住时交还给浏览器）；
  - `cookies`：读取当前网站（或被下载地址）的 Cookie 以同步 / 随下载发给清影；
  - `webRequest`：只观察响应头以发现视频流和文件，不拦截、不修改请求，不读取内容；
  - `tabs`、`activeTab`：获取标签页的网址和标题；整页 / 选区截图时对当前标签页截取可见画面；
  - `scripting`：你点击某个页面功能时注入对应脚本，以及按你开启的功能注册 / 注销常驻脚本；
  - `alarms`：每 30 秒检查一次清影的下载进度和“需要登录”提示；
  - `<all_urls>`（主机权限）：因为用户可能在任意网站登录、下载或观看视频，所以需要读取任意网站的 Cookie、观察任意网站的媒体请求，以及在你开启对应功能后，往你使用的网站里注入脚本；
  - `contextMenus`：右键菜单（用清影下载、稍后看、复制干净链接、以图搜图、页面保存等）；
  - `storage`：保存上述设置、记录和嗅探结果；
  - `notifications`：发送、接管成功或失败时的系统通知。
- 扩展对用户数据的使用，遵守 Chrome 应用店的 Limited Use 要求：仅用于提供上述单一用途，不用于广告，不出售，不用于与功能无关的目的，不由人工读取。

## 清影桌面版

- **下载与解析**：清影直接向你要下载的网站（抖音、B站、YouTube 等）发出请求，就像浏览器一样。不经过清影开发者的服务器——我们没有服务器。
- **本地数据**：设置、解析历史、下载记录、收到的链接、订阅和直播间列表保存在你电脑的应用数据目录中，可在“设置”里清除，卸载时可一并删除。
- **Cookie**：你添加的账号 Cookie 用 AES-GCM 加密后保存在本机，密钥保存在系统钥匙串（不可用时保存在本机应用数据目录），只会发送给它所属的网站。
- **手机发链接到电脑**：默认关闭。开启后在局域网内提供一个小网页，只接受局域网和本机地址的访问，需要访问令牌，新设备需要在电脑上确认配对。不经过任何外部服务器。
- **检查更新**：开启“自动检查更新”后，清影会访问 GitHub 的公开接口获取最新版本信息；这是普通的网络请求，GitHub 可能记录你的 IP 地址，清影不发送其他信息。
- **组件下载**：你在“设置 → 组件”里点击安装时，才会从 GitHub（或你填写的镜像）下载 yt-dlp、ffmpeg。
- **诊断信息**：“复制诊断信息”只是生成一段文字放到剪贴板，已隐去 Cookie 和令牌，由你决定是否发给别人。清影不会自动上传任何诊断信息或崩溃报告。

## 儿童

清影不面向 13 岁以下儿童，也不会有意收集儿童信息（实际上我们不收集任何人的信息）。
