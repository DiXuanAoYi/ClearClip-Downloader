## 名称

发送到清影 ClearClip

## 简短描述（Chrome 限 132 字符）

把网页、链接、视频一键发送到电脑上的清影下载；发现网页里的视频流，可接管浏览器下载、同步登录状态，并带视频播放增强、批量选取、页面截图等小工具。

## 详细描述

“发送到清影”是桌面版下载工具清影 ClearClip 的配套扩展（当前版本 1.9.0）。它只连接你电脑上运行的清影（本机 127.0.0.1），不连接任何外部服务器，不含统计、广告或远程代码。

【功能】
· 发送：点击工具栏按钮，或在网页、链接、视频、音频、图片上右键，把地址一键发送到清影，由清影解析并下载（支持抖音、快手、小红书、B站、微博、Pixiv，以及 YouTube 等上千个网站）。
· 发现视频：打开视频网页后，自动发现页面里的视频流（m3u8、mpd）、视频、音频和图片，在弹窗里按清晰度和大小排列，可勾选多项一起发送。DRM 加密的内容无法下载。
· 接管浏览器下载（默认关闭）：开启后，浏览器要下载的压缩包、安装包、镜像、音视频等大文件会交给清影，用多线程和断点续传下载。可按文件类型、最小文件大小、网站白名单 / 黑名单过滤；按住 Alt 点击链接可临时用浏览器下载；清影没运行或没接住时，下载自动交还给浏览器。
· 同步登录状态：需要登录才能下载的内容（会员视频、年龄限制等），可以把当前网站的登录 Cookie 同步给清影。可选开启“自动同步”，只对你勾选的网站生效。
· 连接状态：弹窗里显示是否已连接清影。
· 下载进度：弹窗里查看清影的下载进度，暂停 / 继续 / 在文件夹中显示；图标角标显示进行中的数量。清影提示某个网站“需要登录”时，扩展询问你是否同步 Cookie。
· 链接清理与二维码：发送前自动去掉 utm_* 等追踪参数（可自定义名单）；本地生成二维码，用手机扫码打开当前页面。
· 页面小工具（可在设置里逐项开关，需要常驻运行的功能默认关闭）：视频悬浮下载按钮；批量选取；页面媒体总览（图片、视频、音频网格，可按尺寸过滤）；图片右键以图搜图（Google、Bing、Yandex、TinEye、百度、搜狗，可自定义）；图片悬停放大和画廊；稍后看列表；页面截图（可见区域 / 选取区域 / 整页）、另存为 PDF、保存为 Markdown、摘录选中文字。
· 播放增强：倍速 0.1×–16×、记住每个网站的倍速、快进快退、截图、画中画、A–B 循环、逐帧、跳过片头片尾、音量增益、画面调整，快捷键可自定义。
· 解除复制 / 右键限制（单独说明，见下）。

【解除复制 / 右键限制】
这是一个可选功能，默认关闭，需要你在弹窗里给某个网站手动开启。开启后，扩展只在你列出的网站里，让页面文字可以选中，并让网站对复制、剪切、右键菜单、选择文字、拖动这几类事件的“禁止”失效。它只解除浏览器端的限制：不绕过付费墙和登录墙，不提取图片里的文字，不破解 DRM。它可能影响依赖这些操作的页面（在线文档、网页游戏、拖拽排序），出问题时在弹窗里对该网站关闭即可。这个脚本运行在网页自己的环境中，不读取页面内容，不联网，也不能调用扩展的任何接口。

【使用方法】
1. 安装并运行清影桌面版（见项目主页），在“设置 → 手机与浏览器扩展”中开启服务。
2. 把端口和访问令牌填到扩展的设置里。
3. 第一次发送时，在清影弹出的窗口里点“允许”完成配对。

【隐私】
· 不收集、不上传任何数据；所有信息（网址、Cookie、文件名）只发送到你本机的清影。
· 不读取浏览记录；发现视频只记录当前标签页里出现的媒体地址，换页面或重启浏览器后清空。
· 自动同步、接管下载、常驻页面功能和解除限制默认关闭（倍速、记住倍速、快进快退仅在页面里有视频 / 音频时才初始化）。
· 截图、页面保存的内容留在你的电脑上；“稍后看”列表保存在扩展本地存储里，不上传；以图搜图只在你点击后，把图片地址交给你选的搜索引擎。
· 仅用于下载你有权保存的内容。

项目主页与源代码：https://github.com/DiXuanAoYi/ClearClip-Downloader

## 单一用途说明（Chrome “隐私权”页签）

把用户选择的网页、链接、视频地址，以及用户选择接管的浏览器下载，连同下载所需的网站登录状态，发送到用户电脑上运行的清影下载工具，用于下载用户有权保存的内容。

## 权限理由（Chrome “隐私权”页签）

| 权限 | 理由 |
| --- | --- |
| `downloads` | 仅用于“接管浏览器下载”功能（默认关闭，用户在弹窗里手动开启）：监听浏览器新开始的下载，符合用户设置的过滤条件时，读取这一个下载的地址、来源页、文件名和大小，取消浏览器自己的下载并把它从浏览器的下载列表中移除，交给用户电脑上的清影下载；清影没有运行或没接住时，用 `downloads.download` 把下载交还给浏览器。不枚举、不读取其他下载记录，不读取下载的文件内容，关闭该功能后不监听任何下载。 |
| `cookies` | ① 用户点击“同步此网站的登录 Cookie”（或对勾选的网站开启自动同步）时，读取该网站的 Cookie，发送给用户电脑上的清影；② 接管一个下载或发送文件 / 图片时，读取被下载地址的 Cookie，只用于这一次下载，不进入清影的账号库。不读取其他用途的 Cookie，不发送到任何外部服务器。 |
| `webRequest` | 仅观察响应头（地址、类型、大小、所属标签页）以发现页面里的视频流（m3u8、mpd）、视频、音频和图片，显示在弹窗里供用户选择发送。不拦截、不修改、不阻止任何请求，不读取请求体或响应体。结果只保存在浏览器的会话存储里，换页面或重启浏览器后清空，不上传。 |
| `tabs` | 读取标签页的网址和标题：用于发现视频时按标签页归类、在图标上显示数量，以及把网页地址作为来源页（Referer）和标题随下载一起发给清影。 |
| 主机权限 `<all_urls>` | 用户可能在任意网站登录、下载或观看视频；浏览器要求读取某网站的 Cookie、观察某网站的媒体请求，必须拥有该网站的主机权限，而网站不能预先枚举。扩展向网站发送的请求只有一种：取回页面里已出现的 m3u8 / mpd 清单文件，用来显示时长、清晰度和是否加密（带上浏览器对该网站的 Cookie，与页面自己的请求一致）。除此之外不向这些网站发送请求。 |
| 内容脚本（`http(s)://*/*`，`bypass.js`） | 只监听鼠标按下 / 点击时 Alt 键是否按住，按住时向扩展后台发送一个固定信号（“这次下载留给浏览器”）。不读取、不修改、不记录页面内容。 |
| 动态内容脚本（`scripting.registerContentScripts`） | 只在用户于设置里开启对应功能后才注册：视频悬浮下载按钮（识别页面里的 `<video>`，在其上显示按钮）、图片悬停放大（读取鼠标下图片的地址并显示大图）、播放增强（控制页面里的 `<video>` / `<audio>`）。这些脚本只在本地处理，不把页面内容发送到任何地方；用户可以按网站关闭。 |
| 解除复制限制脚本（`world: "MAIN"`，动态注册） | **单独说明。** 只注册到用户在弹窗里开启过的网站（默认没有任何网站；“所有网站”是设置里的高级选项）。脚本运行在页面自己的环境里，才能覆盖网站对 `preventDefault`、`oncopy` 等的调用；它只处理 copy / cut / contextmenu / selectstart / dragstart 事件、Ctrl/⌘ + A / C / X 按键和 `user-select` 样式，不读取页面内容，不发出任何网络请求，也不使用任何扩展接口。 |
| `scripting` | ① 用户点击“页面媒体总览 / 批量选取 / 截图 / 保存为 Markdown / 复制干净链接”等功能时，向当前标签页注入对应脚本（用完即走）；② 用户在设置里开启常驻功能（视频悬浮按钮、图片悬停放大、播放增强、解除复制限制）后，注册对应的内容脚本，关闭时注销。注入的脚本全部包含在扩展包内，没有远程代码。 |
| `alarms` | 清影已配置时，每 30 秒检查一次下载进度和“需要登录”提示，用于图标角标和弹窗里的下载列表。 |
| `contextMenus` | 提供右键菜单“用清影下载”、稍后看、复制干净链接、以图搜图、页面保存等。 |
| `activeTab` | 点击工具栏按钮时获取当前标签页的网址和标题。 |
| `storage` | 在本地保存清影的端口、访问令牌、设备编号、自动同步的网站列表、接管下载的设置、功能开关和按网站的规则、快捷键、稍后看列表（最多 300 条）、倍速记忆，以及最近 20 条接管记录（网址和文件名，供弹窗里“改用浏览器下载”）；嗅探结果保存在会话存储里。 |
| `notifications` | 发送、接管成功或失败时显示系统通知。 |

“是否使用远程代码”：否，所有代码都包含在扩展包内。

## 数据使用披露（Chrome 勾选项）

- 勾选：
  - **身份验证信息**：Cookie，仅在用户同步、接管下载或发送文件时读取，只发送到用户本机的清影；
  - **网站内容**：用户主动发送的网址，以及页面里发现的媒体地址和清单信息（只在本机，会话结束后清空）；
  - **网页历史记录**（保守起见）：标签页网址用于发现视频和作为来源页，以及被接管下载的地址；只发送到用户本机的清影，不保存浏览记录。
- 三项声明都勾选：不向第三方出售或转让用户数据；不为与单一用途无关的目的使用或转让；不用于判断信用或放贷。

## Edge “Notes for certification”（给审核人员）

扩展需要配合清影桌面版（Windows / macOS / Linux）使用，下载地址：https://github.com/DiXuanAoYi/ClearClip-Downloader/releases 。
测试步骤：安装并运行清影 → 设置 → 手机与浏览器扩展 → 开启服务，把页面里显示的端口和访问令牌填入扩展设置 → 在任意网页点击扩展图标“发送当前页面”，清影会弹窗请求配对，点“允许”。扩展只连接 127.0.0.1，没有任何外部网络请求（例外：发现视频时取回页面里已出现的 m3u8 / mpd 清单文件；以图搜图只在用户右键点击后打开搜索引擎网页）。设置里的“常驻”功能和“解除复制 / 右键限制”默认关闭；要验证解除限制，在设置的“规则与名单”里把一个网站（例如 example.com）加入名单，或在弹窗“工具”标签里给当前网站打开开关，再打开该网站即可。接管浏览器下载默认关闭，需要在扩展弹窗里勾选“接管浏览器下载”后，用浏览器下载一个压缩包即可验证：下载会出现在清影的“浏览器下载”分类里。

## Firefox 审核说明

扩展代码没有经过压缩、混淆或构建，zip 中的文件就是源代码，不需要另外提交源码。只连接 127.0.0.1（另有取回页面清单文件的请求，见权限说明）。Firefox 版需要 128 或更高版本（解除复制限制使用的主世界内容脚本需要 128）。
