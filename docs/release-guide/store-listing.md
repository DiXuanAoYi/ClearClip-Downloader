## 名称

发送到清影 ClearClip

## 简短描述（Chrome 限 132 字符）

把当前网页、链接或视频一键发送到电脑上的清影下载，并可把网站的登录状态同步给清影。

## 详细描述

“发送到清影”是桌面版下载工具清影 ClearClip 的配套扩展。它只连接你电脑上运行的清影（本机 127.0.0.1），不连接任何外部服务器。

【功能】
· 发送：点击工具栏按钮，或在网页、链接、视频上右键，把地址一键发送到清影，由清影解析并下载（支持抖音、快手、小红书、B站、微博、Pixiv，以及 YouTube 等上千个网站）。
· 同步登录状态：需要登录才能下载的内容（会员视频、年龄限制等），可以把当前网站的登录 Cookie 同步给清影。可选开启“自动同步”，只对你勾选的网站生效。
· 连接状态：弹窗里显示是否已连接清影。

【使用方法】
1. 安装并运行清影桌面版（见项目主页），在“设置 → 手机与浏览器扩展”中开启服务。
2. 把端口和访问令牌填到扩展的设置里。
3. 第一次发送时，在清影弹出的窗口里点“允许”完成配对。

【隐私】
· 不收集、不上传任何数据；Cookie 只发送到你本机的清影。
· 不读取浏览记录和页面内容，自动同步默认关闭。
· 仅用于下载你有权保存的内容。

项目主页与源代码：https://github.com/DiXuanAoYi/ClearClip-Downloader

## 单一用途说明（Chrome “隐私权”页签）

把用户选择的网页地址和所需的网站登录状态发送到用户电脑上运行的清影下载工具，用于下载用户有权保存的内容。

## 权限理由（Chrome “隐私权”页签）

| 权限 | 理由 |
| --- | --- |
| `cookies` | 用户点击“同步此网站的登录 Cookie”（或对勾选的网站开启自动同步）时，读取该网站的 Cookie，发送给用户电脑上的清影，用于下载需要登录的内容。不读取其他用途的 Cookie，不发送到任何外部服务器。 |
| 主机权限 `<all_urls>` | 用户可能在任意网站登录并需要同步该网站的 Cookie；浏览器要求读取某网站的 Cookie 必须拥有该网站的主机权限，而网站不能预先枚举。扩展不会向这些网站发送请求，不注入脚本，不读取页面内容。 |
| `contextMenus` | 提供右键菜单“发送此页面 / 链接 / 视频到清影”。 |
| `activeTab` | 点击工具栏按钮时获取当前标签页的网址和标题。 |
| `storage` | 在本地保存清影的端口、访问令牌、设备编号和自动同步的网站列表。 |
| `notifications` | 发送成功或失败时显示系统通知。 |

“是否使用远程代码”：否，所有代码都包含在扩展包内。

## 数据使用披露（Chrome 勾选项）

- 勾选：**身份验证信息**（Cookie，仅在用户同步时读取，只发送到用户本机）、**网站内容**（用户主动发送的网址）。
- 三项声明都勾选：不向第三方出售或转让用户数据；不为与单一用途无关的目的使用或转让；不用于判断信用或放贷。

## Edge “Notes for certification”（给审核人员）

扩展需要配合清影桌面版（Windows / macOS / Linux）使用，下载地址：https://github.com/DiXuanAoYi/ClearClip-Downloader/releases 。
测试步骤：安装并运行清影 → 设置 → 手机与浏览器扩展 → 开启服务，把页面里显示的端口和访问令牌填入扩展设置 → 在任意网页点击扩展图标“发送当前页面”，清影会弹窗请求配对，点“允许”。扩展只连接 127.0.0.1，没有任何外部网络请求。

扩展代码没有经过压缩、混淆或构建，zip 中的文件就是源代码，不需要另外提交源码。只连接 127.0.0.1。
