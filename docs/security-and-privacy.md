# 安全与隐私

“设置 → 安全与隐私”里有四样东西。先说清楚它们各自能做什么、不能做什么，因为它们保护的对象不一样：

| 功能 | 保护什么 | 不保护什么 |
| --- | --- | --- |
| 应用锁 | 坐在屏幕前的人看不到界面 | 不加密文件；有磁盘访问权限的人可以绕过（见下） |
| 隐私模式 | 不在清影里留下使用记录 | 下载下来的文件本身还在你选的文件夹里 |
| 加密保险箱 | 文件内容和文件名（AES-256-GCM） | 解密出来临时查看的那段时间里，明文在磁盘上 |
| 一键清除 | 清影自己保存的记录、缓存、密钥 | 不会删除你下载的视频文件 |

## 应用锁

设置一个密码（至少 4 个字符）后：

- 每次启动清影都先锁住；也可以在设置里点“立即锁定”、托盘菜单点“锁定”、或按老板键。
- 锁定时界面被整个遮住，托盘迷你窗不再显示任务，系统通知不显示标题，内置播放器和悬浮拖拽窗会关闭。
- 空闲自动锁定（默认 10 分钟没有键盘鼠标操作；设为 0 不自动锁）；窗口收进托盘时锁定（默认开）。
- 输错密码 5 次以后开始限速：先等 30 秒，之后每错一次翻倍，最长 15 分钟。
- **老板键**：设置一个全局快捷键（例如 `CommandOrControl+Shift+H`），按下立刻隐藏所有窗口，设置了应用锁时同时锁定，保险箱也会上锁。

锁定期间下载、订阅检查、直播录制照常进行，手机发送、命令行和网页控制台也照常工作——应用锁只管“有人看屏幕”，不是权限系统。

密码只保存 Argon2id 的校验值，放在加密的密钥文件 `vault.bin` 里，不写进设置文件，也不进入备份。**忘记密码时**可以退出清影，删除数据目录里的 `vault.bin`（同时会清掉保存的 API 密钥）。这也说明：能读写你磁盘的人可以绕过应用锁；要防这种情况请用下面的保险箱和系统的整盘加密。

“禁止截屏和录屏”在 Windows 和 macOS 上让截图、录屏软件只能拍到黑色窗口；Linux 不支持。

## 隐私模式

开启后（侧栏左下角会显示“● 隐私模式”，点一下就能关闭）：

- 不记录解析历史；
- 下载完成的文件不进媒体库，也不写 nfo / info.json，不保存封面缓存；
- 任务结束就从数据库里删除（本次运行期间下载队列里仍能看到）；
- 系统通知只显示“下载完成”之类的固定文字，不显示标题；
- 收件箱（收到的链接）在退出清影时清空；启动时也会补清一次，防止上次异常退出时没清掉。

因为文件不进媒体库，**自动规则、自动上传、AI 自动转写 / 翻译不会对这些文件运行**。订阅和直播间列表是你主动保存的内容，不受影响；日志里仍可能出现链接，需要的话用“一键清除”里的“日志”。

## 加密保险箱

用来放真正敏感的文件。第一次进入“保险箱”页面创建，设置一个至少 6 个字符的密码（和应用锁是两个独立的密码）。**忘记保险箱密码无法找回**，里面的文件也就打不开了。

- 每个文件按 1 MiB 分块用 AES-256-GCM 加密；块序号、文件头和“是否最后一块”都参与认证，所以截断、调换块、改文件头都会被发现。
- 文件名、大小、类型放在另一份加密的目录里，磁盘上只有随机名字的 `.ccv` 文件。
- 随机生成的主密钥用“密码经 Argon2id 派生的密钥”加密保存。修改密码只重新加密这把主密钥，文件不用重新加密。
- 密码输错同样会限速。

**放进去的方式**：保险箱页面“添加文件…”，或在媒体库里多选后“移入保险箱”（加密完成后从媒体库移除记录，并覆盖删除原文件和封面缓存）。

**取出来的方式**：

- “打开”：解密到数据目录下的临时文件夹，再用系统默认程序打开。**这段时间明文在磁盘上**；锁定保险箱、退出清影、应用锁锁定或下次启动时，这些临时文件会被覆盖后删除。
- “解密导出”：解密到你选的文件夹。

保险箱空闲 15 分钟（可调）自动上锁。“覆盖后删除”是写零再删除：机械硬盘上有效，固态硬盘和有写时复制的文件系统不能保证覆盖到原来的位置，所以对安全要求高时请同时开启系统的整盘加密（Windows BitLocker、macOS FileVault、Linux LUKS）。

## 一键清除

按勾选的项目删除，并压缩数据库让旧内容不再留在文件里：

下载任务（进行中的会被取消）、解析历史、媒体库记录（标签、评分、字幕索引；不删文件，回收站里的文件也不动）、收到的链接、订阅与直播间、登录状态（Cookie 和登录窗口里的浏览数据）、API 密钥和通知令牌（应用锁密码保留）、封面与预览图缓存、日志与诊断样本、保险箱里的文件（永久删除）。可以勾选“清除后退出清影”。需要输入“清除”两个字确认。

## 其他保护

- Cookie、API 密钥、WebDAV 密码、机器人令牌都加密保存，不写进设置文件，也不进入备份（备份见[媒体库与工具](library-and-tools.md)）。系统钥匙串不可用时，加密密钥保存在数据目录的文件里，设置页会提示。
- 本机媒体服务（内置播放器用）只监听 `127.0.0.1`，每个文件一个 128 位随机令牌，校验 Host 头，锁定时清空登记。
- 手机发送、网页控制台和 HTTP 接口只接受局域网访问，用令牌保护，传输是明文，不要在不信任的 Wi-Fi 下开启（详见[自动化与集成](automation.md)）。
