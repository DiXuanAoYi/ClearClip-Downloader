# 自动化与集成

## 自动规则

“设置 → 自动化 → 自动规则”：每个文件下载完成后，按顺序检查规则，条件都满足就执行动作（可以同时命中多条）。

**条件**（留空的不限制，填了的必须全部满足）：平台、作者、标题、类型（视频 / 音频 / 图片 / 字幕）、来源（手动 / 订阅 / 直播）、文件大小不小于多少 MB。文字条件可以用 `|` 分隔多个关键词（满足任意一个即可），以 `re:` 开头表示正则。

**动作**：加标签、收藏、移动到子目录（变量同“整理文件夹”）、提取音频（mp3 / m4a / flac / opus）、上传、推送通知。

例：“B站 + 作者含 `教程|入门` → 加标签‘学习’、移到 `学习/{author}`、上传到 NAS、通知我”。

## 自动上传

下载完成后自动上传到 WebDAV（Nextcloud、坚果云、Alist、群晖等）或复制到另一个文件夹（NAS 挂载盘、移动硬盘）。可选上传哪些类型的文件、目标下的子目录规则、成功后是否删除本地文件（删除时走回收站）。WebDAV 密码加密保存。进度显示在“工具箱”的任务列表里。

## 通知推送

下载完成、失败、开播和录制状态、订阅有新内容、登录失效，可以推送到手机或聊天工具：自定义 Webhook（收到 POST 的 JSON `{ app, title, body, text, time }`，可接 n8n、Home Assistant、IFTTT）、Telegram 机器人、Bark、Server酱、企业微信群机器人、钉钉群机器人、飞书群机器人、ntfy。令牌和地址加密保存。每个渠道有“发送测试”。

## 自定义站点规则

内置解析器和 yt-dlp 都不支持的网站，可以自己写一条规则：网址包含的文字、视频地址正则（取第一个括号里的内容）、可选的标题正则和封面正则、Referer、User-Agent。规则优先于其它解析方式，“测试”按钮会显示能否取到、取到了什么。需要懂一点正则。

## 手机与浏览器扩展

见 [phone-send.md](phone-send.md)。浏览器扩展 1.2 还会**嗅探页面里的视频**：m3u8 流和 mp4 / webm / mp3 等文件会出现在图标徽标和弹窗里，一键发送；发送时带上网页地址作为 Referer、网页标题作为文件名，按所在网站归类，所以需要 Referer 才能下载的视频也能下。

## HTTP 接口、网页控制台、命令行

在“设置 → 手机与浏览器扩展”里开启服务后（和手机发送共用同一个服务和访问令牌）：

- **网页控制台**：局域网里的手机或其它电脑用浏览器打开设置页里“控制台地址”（带令牌的地址，路径是 `/console`），可以看下载进度、暂停 / 继续 / 取消任务、添加链接、搜索媒体库。没有令牌的访问会被拒绝。
- **HTTP 接口**（请求头 `X-Token`）：

  | 方法 | 路径 | 说明 |
  | --- | --- | --- |
  | GET | `/api/v1/status` | 版本和下载概况 |
  | GET | `/api/v1/tasks` | 任务列表（不含本机文件路径） |
  | POST | `/api/v1/tasks/pause_all` · `resume_all` · `clear_finished` | 批量操作 |
  | POST | `/api/v1/tasks/<编号>/pause` · `resume` · `cancel` · `remove` | 单个任务 |
  | POST | `/api/v1/add` | 添加链接，正文 `{"text": "..."}`；立即返回，在后台解析 |
  | GET | `/api/v1/library?q=关键词&kind=&tag=&limit=` | 搜索媒体库 |

  接口不返回本机文件路径，也不能删除文件。
- **命令行**：同一个程序也是命令行工具：

  ```
  clearclip add <链接…>        加入下载（清影没在运行时会先启动）
  clearclip list | status      任务列表 / 概况
  clearclip pause|resume [编号|all]
  clearclip cancel <编号> | remove <编号>
  clearclip search <关键词>
  ```

  `add` 直接交给正在运行的清影，不需要开启服务；其它命令通过本机接口控制，从设置文件里读取令牌。加 `--json` 输出原始 JSON。Windows 发布版会接回终端输出。

**安全**：控制台和接口只接受局域网内的访问，传输是明文，请不要在不信任的 Wi-Fi 下开启；令牌泄露后到设置里“重新生成令牌”，旧的二维码和快捷指令都会失效。

## 订阅、直播与播客

- **订阅**可以设置“本地只保留最近 N 个”或“保留 N 天”，超出的按回收站规则清理；每个订阅可设检查间隔、过滤条件、清晰度、保存位置。
- **直播录制**可以设置预约时段：只在这些时段检测开播和录制（不选星期表示每天，结束早于开始表示跨过午夜），时段之外显示“等待预约时段”。
- **播客 RSS**：订阅里可以直接填播客的 RSS 地址，新一集出现时下载音频文件；也支持直接粘贴音频文件地址。
- **省流量模式**与**限速计划**见[桌面体验](desktop-experience.md)。

## 没有做的

- 没有做无界面（Docker / NAS）版本：现在的程序依赖系统的网页内核和托盘，做无界面服务器版需要另外拆出一个只含下载核心和网页控制台的构建，这部分还没有。需要放在 NAS 上长期运行的话，可以在一台常开的电脑上运行清影，用网页控制台从其它设备操作。
- 微信等需要官方应用接入的机器人没有做；上面列出的渠道都是纯 HTTP 接口。
