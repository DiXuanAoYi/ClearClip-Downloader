# 各网站登录说明

大多数公开内容不登录也能下载。遇到“需要登录”“年龄限制”“会员专享”等提示，或想要更高清晰度时，在清影的“设置 → 账号与 Cookie”里添加这个网站的账号。

出错提示里的“登录 XX”按钮会直接打开对应网站的登录。登录保存后，之前因为需要登录而失败的链接（“媒体库 → 收到的链接”）和下载任务会自动重试。

## 三种登录方式

| 方式 | 怎么用 | 适合 |
| --- | --- | --- |
| **内置登录窗口** | 选择网站 → 打开登录窗口 → 在官网页面登录（多数网站可用 App 扫码）。抖音、快手、B站、Instagram、X、Facebook、TikTok 会自动识别登录完成并保存；其他网站登录后点“保存登录状态” | 国内平台和大多数网站，最简单 |
| **浏览器扩展同步** | 安装[“发送到清影”扩展](../desktop/extension/README.md)，在已登录的网站上点“同步此网站的登录 Cookie”；可以勾选“登录状态变化时自动同步此网站” | YouTube 等拦截内置登录窗口的网站；已经在浏览器里登录的网站 |
| **导入 cookies.txt / 粘贴 Cookie** | 用 Cookie 导出扩展导出 Netscape 格式的 cookies.txt 后导入；或粘贴 `a=1; b=2` 形式的 Cookie 后选择网站 | 高级用户 |

清影不直接读取浏览器的 Cookie 数据库：Windows 上的 Chrome 127 起对 Cookie 做了“应用绑定加密”，外部程序读不出来。浏览器扩展是最稳定的办法。

## 内置解析的网站

| 网站 | 不登录 | 需要登录的情况 | 推荐方式 |
| --- | --- | --- | --- |
| 抖音 | 大多数作品可以解析 | 页面拿不到作品信息、被限流；抖音直播接口没有数据 | 内置登录（App 扫码），自动识别 |
| 快手 | 用随机设备标识匿名访问 | 提示“触发了风控”；快手直播页没有数据 | 内置登录（App 扫码），自动识别 |
| 小红书 | 带 `xsec_token` 的完整分享链接可以 | 短链接或缺少 `xsec_token` 的链接、仅登录可见的笔记 | 内置登录（App 扫码），登录后点“保存登录状态” |
| B站 | 最高 720P | 1080P 需要登录；4K、HDR、杜比视界需要大会员 | 内置登录（App 扫码），自动识别 |
| 微博 | 公开微博可以 | 部分微博、仅粉丝可见的内容 | 内置登录（移动版），登录后点“保存登录状态” |
| Pixiv | 普通作品可以下载原图 | R-18 作品，或没有返回原图地址 | 内置登录或扩展同步 |

## 直播录制

| 平台 | 需要登录吗 | 说明 |
| --- | --- | --- |
| B站直播 | 不需要 | 登录后可能可以选更高清晰度 |
| 抖音直播 | 一般不需要 | 程序会自动获取接口需要的 `ttwid`；接口没有数据时再登录 |
| 快手直播 | 经常需要 | 容易触发验证，建议先登录 |
| 虎牙 | 不需要 | |

## 通过 yt-dlp 支持的网站

| 网站 | 需要登录的情况 | 推荐方式 |
| --- | --- | --- |
| YouTube | 年龄限制、会员专享、私享视频，或提示“请确认你不是机器人” | **只能用扩展同步或 cookies.txt**（谷歌会拦截内置登录窗口）。建议在浏览器的无痕窗口登录，同步或导出后关闭该窗口，之后不要在浏览器里再用这次登录，否则 Cookie 很快会失效 |
| Instagram | 大多数帖子、Reels 和快拍 | 内置登录（可能需要邮箱或短信验证），自动识别；或扩展同步 |
| X（Twitter） | 敏感内容、受保护账号、部分推文 | 内置登录，自动识别；或扩展同步 |
| Facebook | 非公开、群组或仅好友可见的内容 | 内置登录，自动识别；或扩展同步 |
| TikTok | 年龄限制或私密视频 | 内置登录，自动识别；或扩展同步 |
| Pornhub | 高清或会员内容 | 扩展同步或 cookies.txt |
| 其他网站 | 看网站 | 优先用扩展同步；也可以在“其他网站”里填写域名后用内置登录 |

## 字幕

- B站的 **CC 字幕和 AI 字幕需要登录**才能获取地址，未登录时解析结果里没有字幕轨（弹幕不需要登录）。
- YouTube 的人工字幕、自动生成字幕一般不需要登录；年龄限制、会员专享视频的字幕同样需要登录。

## 登录状态检查

- 账号列表显示每个账号的 Cookie 过期时间和最近一次检查结果。
- B站、微博会联网验证（B站同时显示是否大会员）；抖音、快手、YouTube、Instagram、X、Facebook、TikTok 检查登录 Cookie 是否还在、是否过期。
- 程序每 6 小时自动检查一次。登录从有效变为失效、或 Cookie 将在 3 天内过期时，会发系统通知；账号旁会出现“重新登录”按钮。

## 安全

- Cookie 加密保存在本机（密钥放在系统钥匙串），只会发送给它所属的网站。
- 登录窗口里是网站官网，没有调用清影的任何权限。
- 使用登录账号大量下载有被平台限制的风险，建议控制频率，必要时使用小号。
