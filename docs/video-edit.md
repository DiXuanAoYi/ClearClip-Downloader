# 剪辑

把几段视频、图片按顺序排在时间线上，裁剪、分割、调整顺序，加转场、文字和配乐，导出成一个新视频。主轨上面还可以叠加多条视频、图片、GIF（画中画、贴纸、水印，见[叠加素材](#叠加素材画中画贴纸gif)）。还可以在一个镜头里框出一个物体，让它被程序持续追踪，再把马赛克、模糊、局部调色或“镜头跟着它走”作用在它身上（见[区域](#区域让效果跟着画面里的物体走)）。

入口：工具箱 → 剪辑。所有处理都在本机完成，需要 ffmpeg（在“设置 → 组件”里安装）。导出的文件登记到媒体库，不会改动原素材。

媒体库里的视频，在详情里点“放进剪辑…”就会直接加到时间线上。

## 界面

- **左上：监视器**。**实时画面**：显示当前播放位置的合成画面，主轨、叠加素材、转场、文字、调色、配乐都直接在里面，改了参数马上就能看到，不用先“生成预览”；下面是播放控制和时间。它是近似效果（见[实时画面和导出的区别](#实时画面和导出的区别)）；要逐帧核对再点“生成精确预览”，用和导出同一套流程渲染一份低分辨率的成片，监视器切到“精确预览”查看。
- **监视器下面的播放条**：`«` `»` 跳到上一个 / 下一个剪辑点，`‹` `›` 退 / 进一帧，播放 / 暂停，当前时间，以及“实时画面 / 精确预览”切换（精确预览过期或正在生成时，下面会多出一条状态条）。
- **右上：检查器**。选中片段、文字或配乐后，在这里改它的属性；选中视频片段时多一个“区域”标签（见下文）；“输出”标签里设置画面尺寸、帧率、画质、编码、格式、文件名和保存位置。
- **下面：时间线**。上方有一排针对红线位置的操作：分割、向左 / 向右裁剪、分离音频、复制、删除、波纹删除，右边是吸附开关、缩放、“适合窗口”和“快捷键”说明。从上到下：文字、叠加轨（叠加 1、2、3……，用到几条显示几条，最后永远多一条空的）、视频（主轨）、音频。视频行里片段首尾相接，每个片段上有素材缩略图；转场让相邻两个片段重叠一段，重叠的部分用斜线标出。顶部的尺子可以点，也可以拖红线定位；右上的滑块缩放时间线。
- 最下面：片段数、总长、输出尺寸和“导出视频”按钮；工程有未保存的修改时会提示。

## 基本操作

| 做什么 | 怎么做 |
| --- | --- |
| 添加素材 | 工具栏上只有一个“添加素材”按钮：点按钮本身是“添加到主轨…”选文件（视频、图片或 GIF，可多选），接在主轨最后；点右边的小箭头可以选“从媒体库添加…”“添加叠加素材…”“从媒体库叠加…”“添加配乐…”“从媒体库添加配乐…”。也可以把文件从资源管理器 / 访达直接**拖到时间线**：落在哪一行就放进哪一行（见下） |
| 叠加素材 | “添加素材”菜单里的“添加叠加素材…”“从媒体库叠加…”：从红线所在的位置开始，叠在主轨画面上（见[叠加素材](#叠加素材画中画贴纸gif)）；选中的主轨片段也可以在检查器里“移到叠加轨（画中画）” |
| 调整顺序 | 拖动视频行里的片段，松手时放到最近的位置 |
| 裁剪 | 拖片段的左右边缘；或者在检查器里填入点 / 出点（`分:秒.毫秒`，不合法的输入会被拒绝）；入点 / 出点旁的“定位”把播放位置跳过去 |
| 分割 | 把红线放到想分开的位置，按 `S` 或点“分割”：分开红线所在的视频片段（选中了某个片段，就分开选中的那个）；离片段两端不到 0.1 秒时不能分 |
| 向左 / 向右裁剪 | 把红线放到想留的位置，选中片段，按 `Q`（去掉红线左边的部分）或 `W`（去掉红线右边的部分），或点时间线上方的“向左裁剪”“向右裁剪”；叠加素材同样可用。没有选中任何东西时，处理红线所在的主轨片段；红线离片段两端不到 0.1 秒时不裁。比先分割再删除少一步，撤回一次就还原 |
| 复制 / 删除 | “复制”“删除”，或 `Ctrl+D` / `Delete`（复制出来的接在原来的后面，被占的地方自动换位置） |
| 波纹删除 | 选中主轨片段，点“波纹删除”或 `Shift+Delete`：删掉这个片段，同时把它后面才开始的叠加素材、文字、配乐一起前移同样的时间，不留空洞（和普通删除不同：普通删除不动别的东西）；撤回一次全部还原 |
| 分离音频 | 选中一个带声音的主轨片段或叠加素材，点“分离音频”：它的声音变成一条同样位置的配乐（可以再单独调音量、淡入淡出、位置），原来的画面静音。图片、没有声音的素材、已经静音的、变速的主轨片段、循环的叠加素材不能分离，会说明原因 |
| 逐帧、剪辑点 | `,` / `.` 退 / 进一帧（按这一段素材的实际帧率，图片按成片帧率），`[` / `]` 跳到上一个 / 下一个剪辑点（片段的分界、叠加素材 / 文字 / 配乐的起止） |
| 应用到全部 | 选中一个片段，检查器里“调色”旁有“应用到全部片段”（把亮度、对比度、饱和度复制给主轨所有片段），“画面方向”旁同样有一个（旋转和翻转），“转场”旁有“应用到所有衔接处”（第一个片段前面没有衔接，不受影响）和“去掉所有转场”；每一项撤回一次就还原 |
| 吸附 | 时间线上方的“吸附”开关：拖叠加素材、文字、配乐时自动靠到片段边界、红线和别的素材的起止上；设置会记住，关掉之后可以随意摆放 |
| 缩放 | 时间线上方的滑块、“适合窗口”，或在时间线上按住 `Ctrl`（macOS 用 `⌘`）滚动滚轮（以鼠标所在的位置为中心缩放） |
| 最近的工程 | “打开…”右边的小箭头列出最近保存或打开过的工程（最多 8 个），点一下直接打开；文件已经不在了会提示并从列表里去掉；“清空最近的记录”只清列表，不删文件 |
| 变速 | 检查器里的“速度”，0.25× 到 4×；变速后片段在时间线上的长度跟着变，声音跟着变速但音高保持不变 |
| 音量、淡入淡出、静音 | 检查器里每个片段单独设置；音量最高 400% |
| 画面方向 | 右转 90° / 180° / 左转 90°，另有左右翻转、上下翻转 |
| 调色 | 亮度、对比度、饱和度三项，可以一键归零 |
| 转场 | 选中第二个及以后的片段，在“转场”里选和**上一个片段**之间的过渡：淡入淡出、闪黑、闪白、溶解、四个方向的擦除和滑动、圆形展开 / 收拢、时钟擦除、马赛克；时长 0.1–3 秒 |
| 图片 | 作为片段加进来，默认显示 5 秒，可以拉长或缩短 |
| 文字 | “添加文字”，在检查器里写内容、设出现和消失的时间、位置（左右 / 上下）、字号、颜色、不透明度、描边、底色块、字体；也可以直接在监视器里拖动文字 |
| 导入字幕 | “添加素材 → 导入字幕文件”，选 SRT / VTT / ASS / SSA（UTF-8 编码），每条字幕变成一条文字（字号 5%、靠下、带描边），按字幕里的时间摆在时间线上，之后可以逐条改内容、时间、样式，撤回一次整批去掉。ASS 只取文字和时间，不保留它的样式、特效和位置；文字最多 500 条，放不下的会提示 |
| 配乐 | “添加素材”菜单里的“添加配乐…”选音频（或带声音的视频），设开始时间、入点 / 出点、音量、淡入淡出、是否循环；可勾选“片段里有人声时自动压低这条配乐” |
| 撤回 / 重做 | 工具栏按钮，或 `Ctrl+Z` / `Ctrl+Y`（macOS 用 `⌘`）；拖一次滑块、拖一次边缘都算一步 |

快捷键（时间线上方的“快捷键”按钮里也有一份）：空格播放 / 暂停，`S` 分割，`Q` / `W` 向左 / 向右裁剪，`Delete` 删除（在“区域”标签里选中了区域时，删除的是区域而不是片段），`Shift+Delete` 波纹删除，`Ctrl+D` 复制，`Esc` 退出画框，`←` `→` 前后 1 秒（按住 Shift 为 0.1 秒），`,` `.` 退 / 进一帧，`[` `]` 上一个 / 下一个剪辑点，`Home` / `End` 到开头 / 结尾，`Ctrl+滚轮` 缩放时间线，`Ctrl+S` 保存工程。焦点在文字输入框里时，这些快捷键不抢输入；点过单选按钮、复选框（比如检查器的标签页）之后快捷键照常生效，只有空格、方向键和回车留给它们自己用。

## 叠加素材：画中画、贴纸、GIF

主轨之外，可以在它上面叠加更多视频、图片和 GIF 动图：画中画、贴纸、水印、动态表情、第二个机位都靠它。叠加素材不占主轨的位置，可以放在**任意时间、任意一条叠加轨**上，多条叠加轨同时出现。

### 怎么加

- **按钮**：“添加素材”右边小箭头里的“添加叠加素材…”（选文件，可多选）、“从媒体库叠加…”。新素材从**红线所在的位置**开始；一次选了多个文件时，它们在**同一条轨上依次排开**（一个接一个，不会叠成一团）；那条轨道这段时间已经有素材，就自动换到最近的空轨。
- **拖文件**：从资源管理器 / 访达把文件拖到时间线上，落在哪一行就放进哪一行。拖到某条叠加轨上，素材从落点的时间开始，放在那条轨上；拖到主轨，按落点插入到对应的位置；拖到音频行，当作配乐；拖到别处，接在主轨最后。拖的时候会高亮落点所在的行和起始时间。不是视频、图片、音频的文件会被跳过并提示；文件夹不能直接拖入，要把里面的文件选中后再拖。
- **把主轨上的片段变成叠加素材**：选中片段，检查器里“移到叠加轨（画中画）”（放在原来的时间上，大小是刚好放进画面；片段上的区域、转场带不过去，会提示）。叠加素材选中后可以“移到主轨”接在主轨最后。

主轨还是空的时候，第一个素材会先放到主轨上——叠加素材要有主轨才会出现在成片里。

### 摆放和调整

- **在监视器里直接拖**：选中叠加素材后，画面上会出现它的边框和四角的控制点——拖里面移动，拖角缩放（保持比例），拖上方的圆点旋转。旋转时靠近 0° / 90° / 180° 会吸附，按住 `Shift` 每 15° 一档。素材的中心最多可以放到画面外半个画面的地方。
- **在检查器里精确设置**：叠加轨（1–8，号越大越在上面）、开始于、入点 / 出点（素材里的时间）、速度（0.25×–4×）、左右 / 上下位置、大小（宽度占画面宽度的比例，100% = 和画面一样宽）、旋转、不透明度、淡入淡出（从透明渐显 / 渐隐，声音同步）、入场 / 出场动画（从上下左右滑进 / 滑出画面，或缩放；各 0.1–3 秒，最长不超过素材的一半）、音量（最高 400%）和静音、亮度 / 对比度 / 饱和度、左右 / 上下翻转，另有“放进画面”“铺满画面”“还原”几个一键按钮。
- **在时间线上拖**：拖素材块左右改开始时间，上下拖到别的叠加轨；拖到最上面那条空轨就新建一条；拖两端改入点 / 出点；会吸附到主轨片段边界、红线、其他叠加素材和文字的起止。同一条轨上时间重叠的素材在时间线上错成几行显示，但画面里仍然按“开始先后”叠放。`S` 分割、“复制”、`Delete` 删除都对叠加素材有效：选中了叠加素材，`S` 分开的就是它（红线要落在它中间）；复制出来的接在原来的后面，那一段这条轨被占了就换一条空轨。
- **GIF**：当作视频处理。默认静音、循环，长度凑够约 3 秒（拉长出点就一直重复）。单帧的 GIF 当图片。图片默认显示 5 秒，素材不够长又勾选了“素材不够长时重复播放”的视频也会循环。

### 规则

- **叠放顺序**：叠加轨号小的在下、大的在上；同一轨内开始早的在下；文字永远画在所有叠加素材的**上面**。
- **不撑长成片**：成片的长度由主轨决定，叠加素材超出主轨结尾的部分被截掉（时间线上用斜线标出，检查器里有提示）。
- **声音**：叠加素材里有声音就和主轨、配乐一起混音，音量可单独调，“静音这个素材”可以关掉。
- **上限**：最多 100 个叠加素材、8 条叠加轨；开始时间最晚 10 小时。
- 叠加素材没有“区域”功能（马赛克 / 追踪只能用在主轨的视频片段上）。

### 支持的素材格式

视频：MP4、MKV、MOV、WebM、AVI、FLV、M4V、TS、MTS / M2TS、WMV、MPEG、3GP / 3G2、OGV、VOB、F4V、ASF、MXF 等，GIF 动图按视频处理。图片：JPG / JPEG / JFIF、PNG、WebP、BMP、GIF、TIFF、AVIF、HEIC / HEIF。音频：MP3、AAC / M4A、WAV、FLAC、OGG / Opus、AIFF、AC3、MKA、AMR、WMA 等。判断以文件扩展名为准，实际能不能读由 ffmpeg 决定：AVIF、HEIC、TIFF 要看你的 ffmpeg 版本有没有对应的解码器，读不出来时会告诉你，换成 PNG / JPG 再试。

## 区域：让效果跟着画面里的物体走

一个镜头里，物体在画面里走动，想只处理它、或者让画面始终对准它，就用“区域”：先在物体上框出一个框，程序在整个片段里持续追踪它的位置，效果再绑在这条轨迹上。典型用法：

- **马赛克 / 模糊**：遮住走动的人脸、车牌、水印，不用逐帧去挪框。
- **局部调色**：只调某个物体的亮度、对比度、饱和度；或者勾选“作用于区域以外”，只让物体保持原色，其余部分调暗、调灰。
- **跟随聚焦**：放大并让取景窗口始终跟着物体；勾选“按成片的比例取景”就是把横屏素材自动裁成竖屏，并跟着人走。

入口：在时间线上点选一个**视频**片段（图片片段不能加区域），检查器切到“区域”标签。

### 怎么做

1. 把红线移到物体**清楚可见**的那一帧（要在这个片段里；不在时检查器会提示“移到片段中间”）。
2. 在“添加区域”里选一种效果。监视器会进入画框状态：虚线框是程序在这一帧前后几帧里**感知到的、正在运动的物体**（点一下就选中它）；没有合适的就自己在画面上拖出一个框，单击一下会放一个默认大小的框。`Esc` 退出画框。
3. 点“开始追踪”：从这一帧出发，向前、向后一直追到片段的两头。有进度，可以取消，取消后轨迹保持原样。追完后监视器里会画出轨迹线，追踪不到的那几段用另一种样式标出。
4. 播放、拖动红线看看框是不是一直压在物体上。追偏了，或者物体被挡住了（检查器会写“约 x% 的时间追踪不到”，“到下一处追踪不到的地方”能直接跳过去）：把红线移到那一刻，在监视器里把框拖回物体上，再点“从这一帧重新追踪”。
5. 在“效果”里调参数；实时画面里能直接看到效果（近似），要看准确效果就“生成精确预览”或导出。

### 手动点：精确调整位置

在监视器里拖动框，会在**这一刻**留下一个“手动点”（轨迹线上的小圆点）：这一刻前后 0.3 秒内程序算出的点被它取代，之后重新追踪也不会改它，追踪会以它为准重新往两边走。“去掉这个手动点”可以撤销。拖框角上的小方块改变大小：默认整条轨迹一起变大变小，按住 `Shift` 只改这一刻。区域的位置在两个点之间按时间线性过渡，所以只要在物体走样的几个位置各拖一下，就能把整条轨迹校准。

### 效果和参数

| 效果 | 作用 | 参数 |
| --- | --- | --- |
| 马赛克 | 把区域打上马赛克 | 马赛克大小 |
| 模糊 | 把区域虚化 | 模糊程度 |
| 局部调色 | 只调区域里的亮度、对比度、饱和度 | 亮度、对比度、饱和度 |
| 跟随聚焦 | 放大并让取景窗口跟着区域走 | 放大（1–4 倍）、按成片的比例取景、镜头平滑（0–5 秒） |

马赛克、模糊、局部调色还有这些通用设置：

- **形状**：方形或椭圆。
- **边缘羽化**：边缘从“有效果”渐变到“没有效果”的宽度。
- **范围扩大**：比框大多少（负数是缩小）。物体动得快、框跟得不太紧时放大一点更保险。
- **作用于区域以外**：反过来，保留区域里面的，处理其余部分。
- **生效时间**：勾选“只在一段时间里生效”后可以填起止时间（素材自己的时间，和入点 / 出点一致；“取播放位置”可以直接取红线所在的时间），只在这段时间内有效果。
- **名称**：可以留空，只是给自己区分用。

跟随聚焦不用形状、羽化这些：它改变整个镜头的取景，**一个片段只能有一个**，也不受“生效时间”限制。镜头平滑越大越稳、跟得越慢。“按成片的比例取景”打开时，取景窗口的形状跟输出的画面比例一致（竖屏输出就是竖条），关闭时窗口和原画面同比例，只是放大。

一个片段最多 8 个区域，叠加的效果按添加顺序依次作用。

### 它是怎么工作的（以及不能做什么）

- **感知运动物体**：比较这一刻前后几帧，扣掉镜头的整体平移后，把还在动的地方圈出来。它**不认识**画面里是什么（不是人脸 / 人 / 车的识别），也看不见一动不动的物体；镜头本身在大幅移动、变焦，或者画面在闪烁时，它感知不出单独的物体（会提示）。感知不到就自己拖框，不影响后面的追踪。
- **追踪**：拿框里的画面当模板，在后面每一帧里找最像的位置（带金字塔的归一化互相关匹配），边追边慢慢更新模板；追不到时那一段的位置是推测的，标成“追踪不到”，物体重新出现后会自动找回。取样用低分辨率的灰度画面（长边 480 像素），取样率按追踪范围的长短定：不超过 2 分钟取每秒 15 帧，不超过 6 分 40 秒取 10 帧，更长取 6 帧；帧与帧之间线性补位。一次最多追踪 30 分钟。
- **框的大小是固定的**：追踪时框不会自己变大变小。物体靠近、远离镜头变大变小时，用手动点和调整大小来校正。
- **容易追丢的情况**：被长时间挡住、形状变化很大（转身、变形）、运动模糊、框里几乎是纯色（没有纹理可以认）、和周围非常像的物体并排走。追丢时程序会告诉你丢了多少、在哪里，剩下的用手动点补。
- **位置和时间怎么存**：位置用“占整个画面的比例”（和素材的显示方向一致，旋转、翻转之后仍然对得上），时间用素材自己的时间，所以分割、裁剪、变速、复制片段之后，区域仍然跟着物体（分割时两半各留下自己那一段轨迹）。
- **导出**：马赛克 / 模糊 / 局部调色先在本机按轨迹逐帧画出“遮罩”（一个很小的灰度临时视频，导出结束后删除；进度里会写“正在生成区域遮罩”），ffmpeg 再用遮罩把处理后的画面叠回去，所以形状、羽化、“作用于区域以外”都准确。需要 ffmpeg 的 `alphamerge`、`overlay`，模糊要 `gblur`，调色要 `lutyuv`，聚焦要 `crop`；缺的话导出前会说明，不会悄悄丢掉。跟随聚焦用时间变化的 `crop` 表达式，位置精确到整像素。
- **不会做的**：不识别人脸 / 人 / 车 / 文字（也就不会按“人脸”自动找到要遮的东西）；图片片段没有区域；“视频规整”里的分段色彩匹配目前不支持排除画面里的某块区域（只能按时间 / 帧号排除）。

## 时间线的规则

- 主轨上的片段首尾相接，没有空隙。转场把后一个片段往前提，和前一个片段重叠“转场时长”这么长，所以总长会变短。
- 转场时长会自动收紧：不会超过前一个片段（扣掉它自己开头的转场）和后一个片段的长度；收紧后不到 0.1 秒就直接切换。检查器里会提示“片段太短，实际转场 x 秒”。
- 第一个片段没有转场。
- 文字、叠加素材和配乐用时间线上的时间（不跟着某个片段走）；超出视频结尾的部分会被截掉，不会把成片拉长。
- 主轨上插入、删除、拖动、变速、转场改变了片段的位置时，叠加素材、文字、配乐**不会跟着挪**，仍然停在原来的时间点。想让它们跟着挪，用“波纹删除”（删除时后面的一起前移）。
- 速度改变的是片段在时间线上的长度，入点 / 出点仍然是**素材里**的时间。

## 输出

- **画面尺寸**：跟随第一个片段；或 1920×1080、1280×720、3840×2160（横屏）、1080×1920、720×1280（竖屏）、1080×1080（方形）、1080×1350（4:5）；也可以自定义。
- **画面适配**（素材比例和输出不同时）：完整显示留黑边 / 铺满并裁掉多余部分 / 完整显示且背景用模糊画面。
- **帧率**：跟随第一个视频，或 24 / 25 / 30 / 50 / 60。
- **画质**：体积小 / 均衡 / 高画质；**编码**：H.264（通用）/ H.265（更小，需要 ffmpeg 里有 HEVC 编码器，没有时自动改用 H.264 并提示）；**格式**：MP4 / MKV。
- 输出统一成一种规格后拼接：声音统一成立体声 48 kHz，没有声音的片段补静音，所以有声和无声的素材可以混着用。

## 工程文件

“保存 / 另存为”把当前时间线存成 `.ccedit` 文件（JSON，只记录素材路径和各项设置，不复制素材）；“打开…”读取。打开时素材找不到的片段会标成红色，选中后点“重新指定文件…”，修好之前不能导出。有未保存的修改时，新建 / 打开前会询问。

没有保存也不用担心：每次改动后约 1 秒会在本机留一份草稿，下次进入剪辑时顶部会提示“找到上次没保存的剪辑”，点“继续编辑”就接着做。

## 实时画面和导出的区别

监视器里的“实时画面”是用系统浏览器内核把素材直接叠在一起播放的：主轨、叠加素材、转场、文字、调色、配乐、区域的效果都在里面，拖时间线、改参数马上看到，不需要先渲染。这是为了反应快，所以**只是近似**；以“生成精确预览”和导出的成片为准：

- **转场**：淡入淡出、闪黑、闪白、擦除、滑动、圆形展开 / 收拢、时钟擦除都按 ffmpeg 的实际形状做了近似；溶解、马赛克这两种在实时画面里用淡入淡出（带一点模糊）代替。
- **声音**：主轨、叠加素材、配乐的音量、静音、淡入淡出都听得到；高于 100% 的音量在实时画面里按 100% 播放，配乐的“自动压低”听不出来。
- **画面**：文字的字形用系统字体；调色、旋转、翻转、淡入淡出是近似效果；画面适配选“模糊背景”时，实时画面显示成“完整显示留黑边”；变速、降噪等处理细节以导出为准。
- **区域**：框和轨迹是准确的（监视器和导出用的是同一条轨迹）。效果只是示意：马赛克 / 模糊 / 调色用浏览器的滤镜近似，不显示羽化，也不显示“作用于区域以外”；跟随聚焦会放大并让取景跟着物体走，但没有算镜头平滑。
- **素材读不出来**：实时画面能不能播某个素材取决于系统的 WebView（某些编码，比如部分 H.265 或 ProRes 素材，可能黑屏或没有声音，监视器上会提示“有素材在实时画面里播不出来”，先用静态画面代替）。点提示旁的“生成预览用的小文件”，程序会把这个素材转成一份 H.264、最高 540 像素的小文件（缓存在应用数据目录的 previews 里，同一个素材只做一次，要等一会儿），实时画面改用它播放；它只用于监视器，导出仍然用原素材。这不影响导出，ffmpeg 能读的素材都能导出。时间线上缩略图读不出来时显示成色块。
- **精确预览**：想逐帧核对，点“生成精确预览”，用和导出同一套流程渲染一份低分辨率的成片（编码速度优先；工程没变化时复用上次的），监视器切到“精确预览”播放。工程一改动，精确预览就标成“已过期”，监视器自动回到实时画面。
- 导出以 ffmpeg 渲染的为准。

## 限制

- 主轨只有一条，要同时出现多个画面用叠加轨（画中画、分屏靠摆放位置和大小做）；叠加素材的位置、大小、旋转、不透明度是固定值，只有入场 / 出场两种动画，没有自由的关键帧，也没有波形、抠像、特效库；文字是单一样式的静态文字（多行靠换行，左对齐），没有逐字动画。叠加素材没有转场和区域，要“一出现就渐显”用淡入，要“从边上进来”用入场动画。
- 最多 300 个片段、100 个叠加素材（8 条叠加轨）、500 条文字、20 条配乐；每个片段最多 8 个区域（其中跟随聚焦最多 1 个）。
- 转场需要 ffmpeg 的 `xfade`，文字需要 `drawtext`，自动压低配乐需要 `sidechaincompress`。精简版 ffmpeg 里缺少的滤镜会在导出前说明原因（并给出安装完整版的提示），不会悄悄丢掉。精简版没有 libx264 时，和工具箱里其他功能一样按 ffmpeg 里有的 H.264 编码器兜底（例如 libopenh264），画质和速度和完整版略有不同。
- 剪辑导出时不做 HDR → SDR 转换，HDR 素材画面会发灰。选中 HDR 的片段或叠加素材，检查器里会提示，点“转成普通画面并替换”：用视频规整的“通用兼容”预设只做 HDR → SDR（尺寸、帧率、声音都不动），转完放在原文件旁边，时间线上用到它的地方自动换成转换后的文件，撤回一次就换回原素材。也可以先在“视频规整”里批量转好再剪辑。
- Windows 的命令行有长度上限。片段非常多、特效很复杂时，滤镜图超过 12000 字符就写进临时文件交给 ffmpeg；万一连参数本身也超长，会明确提示“命令行太长”，这时把工程拆成几段分别导出再拼接。
- 文字默认字体：Windows 用微软雅黑，macOS 用苹方，Linux 找系统里的中文字体；可以在每条文字里选一个字体文件（`.ttf` / `.otf` / `.ttc`）。
- 素材在时间线上之后又被移动、改名或重新编码，导出时会重新检查；入点 / 出点超出素材长度时按素材实际长度收紧并提示，整个超出则拒绝。

## 和别的功能的关系

- 想先统一规格、再剪辑：先用[视频规整](video-normalize.md)，再把结果放进剪辑。
- 想给多个来源的片段拉齐色调：先拼好，再对成品做规整里的“分段色彩匹配”。
- 想在一个镜头里遮挡 / 调色某个运动物体：用本页的“区域”；想按时间段排除一部分画面不参与“分段色彩匹配”：在视频规整里设置排除的时间段。
- 想做字幕：剪辑里的文字是画面上的静态文字；有时间轴的字幕请用工具箱“字幕”标签，导出后再烧录。
