# 批量下载与下载队列

一次添加多条链接时，清影把它们组成一个**批次**：先预览确认，再整批加入队列，队列里按批次管理。

## 入口

| 入口 | 行为 |
| --- | --- |
| 剪贴板一次复制 ≥ 2 条链接（主窗口在前台、没开“自动下载”） | 弹出“批量添加…/只解析第一条” |
| 解析页粘贴多行链接 | “批量添加…”按钮 |
| 拖入或导入 `.txt` `.csv` `.md` `.html`（书签导出） | 直接打开面板；文件上限 8 MB |
| 浏览器扩展 → 工具 → “本页所有视频链接 → 批量下载” | 扩展收集页面里像视频页的链接（最多 500 条），发给清影，电脑上打开面板（需要已配对） |
| 手机 / 浏览器发来的一条消息里有多条链接 | 自动建批次（来源写发送设备名） |
| 悬浮窗、迷你窗里多条链接 | 自动建批次 |
| 收到的链接 → 勾选多条 → “批量添加所选…” | 打开面板 |

设置 → 下载 → 批量下载里可关闭“先预览”，关闭后上述入口直接按默认选项整批加入。

## 预览

逐条解析（同一网站放慢速度），每条结果实时出现：

- **可下载**默认勾选；**重复**（同一视频，或去掉 `t` `si` `spm_id_from` 等跟踪参数后相同）、**已下载过**、**已在队列**默认不勾；
- **需登录**可直接去登录；**不支持**显示原因；
- 播放列表 / 合集显示“展开 N 项，下载第 a 到 b 项”，加入队列后按批次间隔逐条解析；
- 单次最多 **500** 条，超过提示分批。

## 整批设置

清晰度、保存位置、批次文件夹（默认 3 条起开启，用批次名当文件夹名）、同时下载数（1–5）、条目间随机间隔、整批限速、完成后动作、只在设定时段下载。文件名模板里可用 `{index}`（批次序号，按总数补零，如 `03`）。

## 队列

- 每个批次一张卡片：进度条、下载中 / 排队 / 待解析 / 暂停 / 失败；整批暂停、继续、取消、清理已完成、删除批次；
- “只重试失败项”会重新继续失败的任务，并重新解析当时解析失败的链接；“导出失败清单”写出 txt（每个失败项一行说明加一行链接），可直接拖回清影；
- 单条失败不影响同批其他条目；
- 批次与未解析的链接保存在本机数据库，关闭程序后下次启动继续。

## 调度规则

- 全局同时下载数、每个网站同时下载数仍然生效；批次并发数是在它们之内再加的一层上限；
- 同一网站相邻两条开始之间随机等待（批次设置里的区间）；
- 批次限速与全局限速取较小者；yt-dlp 下载无法共用限速器时，把批次限速平均分给批次里同时下载的任务；
- “只在设定时段下载”：设置里给出时段（可跨午夜、可选星期）；时段外暂停，或填“时段外限速”继续慢速下载；
- 批次里所有任务结束后，按批次的“完成后”执行一次（关机 / 睡眠有 60 秒可取消的倒计时）。
