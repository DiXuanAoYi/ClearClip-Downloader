没有焦点输入框时的两条路
全局快捷键
在任何程序里按 Ctrl + Alt + J，处理选中文字；没选中则处理整段。
托盘菜单
托盘图标右键：暂停浮标 1 小时 / 本程序不再显示 / 打开写作面板。
桌面端怎么工作
发现输入框监听 Windows 的焦点变化事件，读出当前聚焦控件是否可编辑，再显示浮标。
读取文字优先用系统无障碍接口读取选区和全文；读不到的程序，退回“模拟复制”，并还原原来的剪贴板。
写回文字优先用无障碍接口直接写入；不行就“模拟粘贴”，同样还原剪贴板。
浮标窗口置顶、不抢焦点、不进任务栏、点击穿透空白区域，所以不会打断正在输入。
绝不弹出密码框、游戏全屏、演示放映、清影自己的窗口。
与扩展去重浏览器里装了清影扩展的页面，桌面端不重复显示；扩展无法注入的页面（浏览器设置页、PDF 阅读器）由桌面端接手。
不确定的点部分程序（如用自绘控件的软件、一些游戏聊天框）读不到文字，只能用快捷键方式；这点需要开工后用真实软件逐个测试。
先做 Windows；macOS 随后（需用户授予“辅助功能”权限）；Linux 只提供快捷键方式。
