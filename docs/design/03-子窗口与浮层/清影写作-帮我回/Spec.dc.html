把“回复”做成“帮我回”

现在的“回复”只是动作条里的一个按钮，意思全靠在“额外要求”里打字。改成两个维度点选：我的意思（说什么）× 怎么说（语气），再加上对方是谁。

你提的 9 项放在哪

正式得体→怎么说正式得体
高情商回复→怎么说高情商
幽默接话→怎么说幽默接话
体面拒绝→我的意思拒绝 ＋ 怎么说高情商（选“拒绝”时默认就是这个搭配）
答应但设条件→我的意思有条件地答应（多一个“条件”框）
答应 / 拒绝→我的意思原样保留
再想想 / 问清楚→我的意思原样保留，各带一个小表单

分成两组后可以自由组合（5 × 5 = 25 种），比列 9 个平铺的按钮更好选；我补了“简短干脆”“温暖真诚”两种语气，“对方是谁”和“长度”。

和现有功能怎么合

回复→顶部第一个标签“帮我回”
改写 · 润色 · 更简洁 · 缩短 · 更礼貌 · 更有说服力→“改写润色”标签：选“怎么改”，和帮我回共用同一排语气
语法检查→“检查”标签
翻译 · 总结 · 续写 · 划词工具 · 摘录→“翻译 · 更多”标签
场景模板（小红书、周报…）→留在“改写润色”里；“客服回复”挪进帮我回，变成“对方是：客户”

规则

什么时候进按快捷键时，取到文字的程序是微信、QQ、钉钉、飞书、企业微信、Outlook / 邮件，就直接停在“帮我回”；别的程序停在上次用的标签。顶部小标签写来源和对方名字（能读到时）。
看懂了生成前先用一句话说出对方要什么、给了哪些信息、语气怎样；“问清楚”时顺便列出没说清的地方。这一步很短，跟着回复一起出，不多等。
对方是谁上级 / 同事 / 客户 / 朋友 / 家人 / 不太熟。按称呼和来源先猜一个，可以改；按“程序 + 对方名字”记住，下次自动选上。邮件会自动带称呼和落款。
我的意思五选一，各带一个小框：答应（还想说，可选）、有条件地答应（条件，必填）、再想想（什么时候答复）、问清楚（要问的，可勾选）、拒绝（理由可不说，可以给个替代：改天 / 推荐别人）。
怎么说正式得体 / 高情商 / 幽默接话 / 简短干脆 / 温暖真诚，单选；长度：一句话 / 正常 / 详细。上级、客户时“幽默接话”会提示“可能不合适”，但不拦。
结果一次出三版，各有一个说法标签（稳妥 / 热情 / 简短），Alt+1/2/3 切换。下面一排“微调”：更软一点、更硬一点、再短点、去掉客套、加个表情，点一下就在当前这版上改，不重新选。
不乱说理由、时间、条件只用你写的；你没给理由时不替你编（拒绝就只说“这次没法”），不多答应你没答应的事。结果里出现原文没有的数字或时间，会标黄提醒核对。
上下文“＋ 贴上前面的聊天”可以多贴几条之前的消息，只用来理解，不会回复它们。
写回“替换到微信”写回原输入框（和现在的“替换原文”一样），按钮名跟着来源变；收藏的回复在“翻译 · 更多 › 我的收藏”。
外观沿用写作窗现有的主题色和组件，亮色、暗色都适配；窗口宽度不变（420），内容多时中间滚动，生成按钮和结果始终在下面。
