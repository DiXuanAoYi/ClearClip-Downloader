剪辑多轨遗留项设计

剪辑多轨：五个遗留项的设计

1.13.0 的更新记录里没做的五项：联动 / 分组、复合片段、代理素材、电平表、滑动修剪。每一项先给最小可用的做法和界面示意，你看过再动手。大小按“一个独立的 PR”估。

1. 联动 / 分组 建议先做

中只改工程文件，不动导出

视频和它的声音、字幕放在不同轨道上，现在移动、剪切、删除要逐条做，容易错位。

  • 选中几个片段，按 Ctrl+G 或右键“编成一组”；再按一次拆开。
  • 组里任何一个被移动、分割、删除，其余同步；单独修剪边缘不联动（和主流剪辑软件一致）。
  • 分离音频（已有）自动把视频和分出来的声音编成一组。
  • 数据：每个片段加一个可选的 group 字段；旧工程没有这个字段，行为不变。

2. 复合片段

大要改导出的构图方式

把一段多轨的内容（片头、转场加字幕）收成一个片段，在主时间线上当一条用。

  • 选中若干片段，右键“合成复合片段”；主时间线上变成一条，双击进入里面继续剪，点面包屑退出。
  • 数据：工程里多一个 compounds 表，每个复合片段是一份独立的子时间线；主时间线的片段引用它。
  • 导出：先把子时间线当作一个素材渲染，再放进主时间线。嵌套限制 3 层。
  • 风险最大的一项：预览、导出、撤销、保存都要认识“嵌套”，所以放在联动之后做，并先做导出一致性的测试。

3. 代理素材 建议第二个做

中只影响预览

4K、HEVC、HDR 素材在多轨里预览会卡。现在只有“系统播放器解不了的素材”才会生成预览用的小文件。

  • 设置里加“预览用小文件”：关 / 仅解不了的（默认，和现在一样）/ 超过 1080p 的也生成。
  • 小文件放在工程的缓存目录，用素材路径 + 修改时间做键；素材改了自动作废。
  • 导出永远用原素材，不受影响；预览区右上角在使用小文件时显示“预览代理”标记。
  • 已有的机制（proxy.cjs 测试的那条路径）复用，主要加判断条件和缓存清理。

4. 电平表

小到中只读显示

混音器里现在只有推子，看不出哪一轨太响或削波。

  • 每条轨道的推子旁边一个竖条电平，主输出一个立体声的；单位 dBFS，-6 以上变黄，0 变红并保持 2 秒的“削波”标记。
  • 只在预览播放时更新；用预览用的 Web Audio 分析节点取，不碰导出。
  • 导出前的响度（LUFS）显示已有，这里不重复。

5. 滑动修剪（滑移 / 滑动）

小到中改时间线的拖动逻辑

不改片段长度，只换它用素材里的哪一段（滑移）；或者把片段在前后两个片段之间挪动，前后各自补偿（滑动）。

  • 工具栏加两个工具，快捷键 Y（滑移）、U（滑动）；拖动时预览区显示四格：前一帧、本片段入点、出点、后一帧。
  • 滑移只改片段的入点和出点（保持时长）；滑动改前一个的出点、后一个的入点，总时长不变。
  • 素材边界处停住，不允许拖出素材范围；可撤销，和现有的修剪共用一套撤销记录。

要你定的：做哪几项、什么顺序。我的建议是 1 联动 → 3 代理素材 → 4 电平表 → 5 滑动修剪，最后才做 2 复合片段（它牵涉预览、导出、撤销和保存的整体改动，风险最大）。每一项做完都推到分支，在你确认前不合并。
