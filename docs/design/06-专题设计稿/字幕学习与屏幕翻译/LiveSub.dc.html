字幕模式 · 以及怎么分期做

看视频、直播、游戏过场时，只盯画面下方那一条字幕。字幕换了才翻译；一句话分成两行、两屏出现时，等它说完再合成一句。

①只框一条字幕带，译文盖在原位
あの日から、ずっと探していたんだ。
字幕带 · 640×44 · 6 帧/秒
②翻译后（双语，原文小字）
从那天起，我一直在找你。あの日から、ずっと探していたんだ。

想请你拍板的几件事

  1. 识字引擎：默认用 Windows 自带的文字识别（零下载、很快，但要装对应语言包），再提供一个“增强识字组件”按需下载（准确率更高、语言更多）。这样可以吗？
  2. 漫画模式默认走视觉模型，会上传图片，开启前提示一次。可以接受吗？还是宁可本机识字、准确率低一些？
  3. 第一期只做 Windows（你的游戏场景基本都在 Windows 上）。
  4. 控制条：做成像 Bubble Translate 的小悬浮钮，还是只用托盘 + 快捷键？
  5. 系统声音实时字幕（把游戏或视频的声音实时转成字幕再翻译，借鉴 win_subtitle）：要不要排进后面的期次？
第一期 · 标准模式能翻、能贴、不闪窗口 / 区域取景、变化检测、本机识字、整屏批量翻译与缓存、透明贴字层、控制条与快捷键、截图时排除自己。复用：模型池 · 术语库 · 专家 · 已有的透明窗口与截图窗口
第二期 · 字幕模式字幕带 + 合并断句固定字幕带、更高刷新、字幕去重、跨屏断句合并、悬浮条。复用：字幕工坊的断句与双语样式
第三期 · 漫画模式气泡 + 竖排 + 擦字气泡检测、视觉模型竖排识字、取色填充 / 邻近修补、翻页续翻、拟声词旁注。复用：已做的截图翻译（视觉模型）接口
第四期 · 打磨按程序记设置每个游戏单独的区域 / 模式 / 术语库、翻译历史、更多识字语言；可选：系统声音实时字幕。复用：SenseVoice 本机语音识别
