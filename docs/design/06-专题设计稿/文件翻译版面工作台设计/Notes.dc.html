借鉴 Adobe Color 的构思

  • Color wheel：色轮上一组点联动，选配色规则，一次得到 5 个颜色（图 5）
  • Extract from image：从原页取一组颜色，带“多彩 / 明亮 / 柔和 / 深色 / 暗”风格，圆点可拖（图 4）
  • Extract gradient：沿原页上一条线取渐变，给“渐变背景”用（图 4）
  • Accessibility / Contrast analyzer：对比度大数字、AA / AAA 逐项、一键“保持色相调明度”、色盲下重新算对比度（图 5）

需要你确认的

  1. color_utils.py：color_dialog.py 引用了 widgets/color_utils（颜色名称表、色盲矩阵、安全色域钳制）但没在附件里。能给我的话，名称和模拟值会和 weld_app 完全一致；不给，我用标准公式重写，只有“名称”一栏会有差异。
  2. 页面颜色“反了”没能在真机验证：想用真实 PDFium 渲染纯红页，这个环境不允许运行下载来的程序。动手时我先写这个检查放进测试；你也可以用一份纯色块 PDF 对一下。
  3. 几个默认值：字号保持原字号、框往下长，碰到别的块才缩，最低 85%；背景外扩 = 字号 × 18%，至少 2 磅；换行“句号处保留换行”；进版面工作时左栏自动收成图标条；整份文件的颜色替换先显示改多少处再确认。
  4. 安全色域（BT.709）：做 PDF 用不到，我放进“高级”默认关。要不要保留？
