摘要面板：收到右边、再弹出来

现在的面板只有“打开”和“✕ 关闭”两种状态，想暂时让开就得关掉，再开要等重新读取。加一个收起：面板滑到右边，只留一个小标签；点它或停在上面就能弹出来，摘要、文稿、问答、笔记都在，不丢。

展开现在的样子，多一个“⇥”。点页面别处不会收起（免得看文稿时误关）。
⇥ 或 Alt+Shift+S
点标签
收起只剩右边 30 像素的小标签，不占页面、不挡内容、不挤开网页。
停 0.35 秒
移开 0.8 秒
预览面板盖在页面上，带“预览条”；点固定或在里面点任何地方就变成展开。
快捷键Alt+Shift+S：没打开 → 打开并展开；展开 → 收起；收起或预览 → 展开。想真的关掉点 ✕。视频胶囊菜单里的“关闭视频摘要”不变，旁边加一项“收起到右边”。
✕ 关闭和现在一样：小标签也消失；正在生成的任务照旧继续，下次打开自动接上。
小标签宽 30、高 84，贴右边缘，上下拖动换位置，记住位置（所有网站共用）；默认在窗口高度 38% 处，会躲开视频右下的播放胶囊。平时半透明，鼠标过去变实并展开成“视频摘要 ‹ Alt+Shift+S”。
看得到进度收起后也要知道发生了什么：生成中，图标外一圈转动；生成好了，绿点 + 旁边弹一句“摘要生成好了 · 点开看”（6 秒淡出，绿点留到你打开为止）；没设置大模型 / 读不到字幕，琥珀点 + 一句原因。
误触预览要在标签上停够 0.35 秒才弹，路过右边缘去拖滚动条不会触发；预览中鼠标移开 0.8 秒才收回，不会一抖就缩。
设置扩展设置里“视频摘要”两个开关：“打开时默认收起到右边”（默认关，开着时用快捷键打开直接是小标签）；“鼠标停在小标签上时预览”（默认开）。
外观配色沿用面板的亮色 / 暗色；滑出、收回 180 毫秒，系统设了“减少动态效果”时直接切换；视频全屏时标签随网页一起隐藏。
没这么做不做成漂浮圆球：会盖住页面，也容易和视频胶囊、悬浮球挤在一起；不挤开网页（网页布局不动，不会引起视频重新排版）。
