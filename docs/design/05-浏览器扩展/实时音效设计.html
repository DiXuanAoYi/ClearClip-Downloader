处理链

每一环可以单独绕过；全部关闭时，声音等于没接这条链。默认只开响度标准化和限幅器。

默认关均衡器人声增强、低音、高音、夜间（压低低频）
→
默认关混响房间 / 客厅 / 大厅 / 剧场；程序生成脉冲响应，混合量可调
→
默认开响度测量K 计权 + 400 ms 滑动窗，换算 LUFS（短时 3 s）
→
默认开增益调整按目标与测量值的差慢慢调；有最大增益，静音段不乱拉
→
默认开压缩 / 限幅温和压缩，最后一环限幅，峰值不超过 -1 dBTP

需要你确认的几处

默认值响度标准化开、预设“温和”、-16 LUFS、限幅器开；均衡器和混响默认关。
按网站记忆每个网站可单独关闭，设置保存在浏览器里；弹窗底部和视频上的小面板都能一键关闭本站。
不能处理时只提示，不改声音；提示每个页面最多出现一次，可选择“不再提示”。
耗电与延迟只在视频播放时处理，暂停和标签页在后台时停止测量；响度测量窗口会带来约 0.4 秒的反应延迟，换视频时先快速拉到目标再放慢。
