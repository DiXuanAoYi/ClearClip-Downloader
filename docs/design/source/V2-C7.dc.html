按窗口高度的三种形态

窗口高度侧栏形态尺寸行为
≥ 700图标 + 11px 标签宽 88，导航项 52 高9 个入口 + 设置 + 监听全部可见，无需滚动
560 – 699同上，中间区可滚动同上logo 在顶、设置 / 监听钉在底；中间滚动，上下渐隐，滚动条 3px
< 560 或手动收起仅图标宽 56，导航项 40 高悬停 / 聚焦出现提示（右侧，z-tip）；队列徽标保留

改动说明

1现状问题：900×700 下 logo 被推出视口，侧栏无滚动，底部“下载中 2 · 等…”被截断（审计 #15）。
2导航项更矮：64 → 52px，间距 6 → 2px。9 项 + 设置 + 监听在 700 高度下刚好放得下，约剩 64px。
3页脚短文案：只留“● 监听”（8 字符内）；“下载中 2”这类状态已经在队列徽标和页头胶囊里，侧栏不再重复。
4徽标语义：队列徽标 = 未完成任务数。收件箱类数字（未处理）用不同形状（圆点 + 数字在标签里），避免“3”同时指两件事。
5手动收起：侧栏底部（设置上方）一个“收起/展开”图标按钮，记住选择；矮到 < 560 自动仅图标。过渡 320ms，reduced-motion 下无过渡。
