统一的结构

1图：64px 圆角块，线性图标 28px，强调色字 + 浅琥珀底；整页一个、卡片内一个、紧凑行 40px。
2标题：16px / 700，是“还没有…”或“没有符合…”，告诉用户现在的状态。
3说明：12px，≤ 2 行，最宽 320px，说明“出现什么”或“怎么开始”。
4操作：0–2 个。有明确下一步 = 一个主按钮；还可以带一个文字链。主按钮文字就是动作。
5替换而非叠加：空态占据整个列表区，不留空表头、不留 0 值统计卡。
6加载在前：数据没回来先骨架，回来为空才显示空态，避免空态与转圈叠加。
