屏幕翻译

翻译别的软件和游戏画面上的文字，译文贴在原位，不挡鼠标

1. 翻译哪里

取景方式“跟随窗口”先在下拉框里选窗口；框选后译文会盖在原处
翻译这个窗口或从窗口列表选
刷新速度越快越费资源
术语库 / 专家按当前软件自动匹配
没认出文字时可以换识字引擎，或检查识字语言是否装了。

2. 模式

译成什么语言留空 = 用“设置 → AI”里的目标语言
同时显示原文（小字）
数字、符号、已经是目标语言的文字不翻省请求，也避免把专有名词翻坏
图标不识别、不翻译人像、齿轮、铃铛这类图标常被认成“8”“©”“Q”
清影悬浮窗里放屏幕翻译控制桌面悬浮窗多一个“译”按钮
字幕模式
