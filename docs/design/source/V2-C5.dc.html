改动说明

1两层 tab 合并：顶部只留一层 5 个 tab（帮我回 / 改写润色 / 检查 / 翻译·更多 / 人设）；原来的第二层（改写、润色、更简洁…）变成内容里的 CcSegmented“怎么改”。一层是页面，一层是动作，外观不再相同。
2原生 select → CcSelect：“场景”“听写”与 Element 输入同高同圆角、同聚焦环；菜单样式统一（第三张图）。
3“修改”从默认橙色下划线变成 CcLink；结果区的“复制 / 替换原文”是 S 号次按钮。
4禁用的“生成”不再是淡琥珀：禁用色对比度 ≥ 4.5，并在旁边写原因（“先填原文”）。
5生成中用骨架；失败用带“重试 / 查看详情”的 Toast，不自动消失。
6写作窗是独立小窗口，所以画 480×720，不画 1280/900；深浅色各一张，浅色版本之前缺失。
