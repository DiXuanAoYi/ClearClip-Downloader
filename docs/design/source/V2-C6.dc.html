改动说明

1高频工具快捷卡：剪辑、截图、转 GIF、压缩视频四个入口放在首页最上，一次点击进入；不新增侧栏一级入口。其余工具仍在左侧分组里。
2分组色点去掉（蓝/橙/紫/绿/粉是全局唯一的彩色，与琥珀 + 青气质冲突）：分组名用 11px 等宽灰标签，选中项用强调色。
3禁用要说明原因：没有文件时“开始处理 / 加入队列”禁用，旁边一行“先把文件拖进文件篮，或点‘添加文件’”；文件篮空态有“添加文件”按钮。浅色 1280 是有文件的正常态。
4900 宽：左侧分组收成顶部 CcSelect；文件篮挪到参数上方，三列错位问题消失（参数卡与预览卡不再各自一列）。
51280 下三列：分组 200 / 主区自适应 / 右栏 280，右栏的文件篮与预览顶部与参数卡对齐，卡片同圆角同内边距。
