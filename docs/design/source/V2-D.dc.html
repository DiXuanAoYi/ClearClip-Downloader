验收标准

截图对照浅 / 深 × 1280×800 / 900×700 四张基线图，与本稿对应画板逐页肉眼对照；PR 里贴新旧对比。差异 > 2% 的区域必须有说明。
对比度 ≥ 4.5:1脚本遍历 --cc-fg / mute / faint / acc-text / ok-text / err-text / info-text / warn-text 对 card、bg 的组合；< 4.5 红灯。大字（≥ 20px）≥ 3:1。
焦点环可见Tab 走一遍每个页面，每个可聚焦元素出现 2px 强调色环（对相邻底色 ≥ 3:1）；鼠标点击不出现。e2e 里对 focus-visible 取样断言。
窄屏无溢出900×700 下每个页面 document.scrollWidth ≤ clientWidth；侧栏可滚动，logo 与设置入口始终可见；设置、队列、屏幕翻译不出现被截断的按钮。
动效reduced-motion 下无位移动画；列表进出、页面切换时长取令牌，不再有裸的 transition: 0.3s。
清理指标字号 .5 值 0 处；圆角只出现令牌值；.vue 内 hex 字面量仅剩白名单；原生 select 0 处。
