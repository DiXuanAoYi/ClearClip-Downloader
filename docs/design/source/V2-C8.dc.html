改动说明

1筛选收成一个按钮：5 个下拉 + 2 个复选框原来比内容还重。现在工具条只有 搜索 / 筛选 / 多选 / 工具 / 视图；点“筛选”弹出一块弹层（深色 1280），里面平台、类型、排序、两个开关，底部“重置 / 应用”。
2已生效的筛选显示为可移除的小标签（平台：B站 ×），旁边“清除筛选”；按钮上带数字徽标。浅色 1280 展示这个状态。
3空状态（深色 900）：CcEmpty，主操作“去解析链接”，文字对比度 ≥ 4.5（原来几乎与白底同色）。加载状态（浅色 1280）：骨架卡片，不再整页转圈。
4复选框换成 CcSwitch 小号并统一行距，“只看收藏 / 只看文件已丢失的”间距一致。
5硬编码的 #f5b73b / #e6a23c / #fff 换成 --cc-warn / --cc-on-acc，浅色下收藏星对比度由 1.9 → 6.1。
6900 宽网格自动 3 列，工具条换行而不是裁切。
