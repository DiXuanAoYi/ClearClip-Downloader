改动说明

1每个分类页右上不再有“// 设置页排布”。页头只剩分类标题；右上是已自动保存状态胶囊。第一眼看到的是内容，不是版式开关。
2“设置页排布”搬到“通用 → 外观与行为”，是一行标准 CcField，带一句说明。深色 1280 是下载分类页（无开关），浅色 1280 是通用页（框出新位置）。
3分类导航固定 200px（900 宽收到 160px），当前分类 = 强调色字 + 浅琥珀底 + 1px 强调线，不再用阴影。
4搜索设置保留，Ctrl K 键帽用 CcKbd；搜索框与分类同宽。
5页面边距 24px（900 宽 20px）；底部渐隐替代原来的“修改即时生效”脚注行，保存状态只在页头一处出现。
