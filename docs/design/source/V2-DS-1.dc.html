令牌 --cc-ease-out / --cc-ease-io / --cc-ease-in。只动 opacity 与 transform，不动 width/height/top。prefers-reduced-motion 下位移去掉、时长归零，见“加载 · 错误 · 反馈”。

焦点环

输入框队列
  • 只在键盘聚焦时显示（:focus-visible），鼠标点击不出现。
  • 2px 实线，偏移 2px，颜色 --cc-focus = 强调色；对相邻底色 ≥ 3:1（深色 10.3、浅色 5.6）。
  • 全局一条规则覆盖：:where(button,a,input,select,[tabindex]):focus-visible；不再逐组件写 outline。
  • 输入框聚焦同时把边框改成强调色；Element Plus 控件用同一令牌覆盖。
