改动说明

1“选择目标”是首屏唯一的主按钮（L 号 44px），点开菜单选 框选区域 / 点选窗口 / 整个屏幕。原来一行里 3 种入口并排（框选 / 点选 / 翻译这个窗口）主次不清。“从窗口列表选”降成下面一行次要入口。
2开始翻译在选好目标前禁用并说明原因；选好后“选择目标”降为“重新选择”（次按钮），“开始翻译”升为主按钮。任何时刻只有一个主按钮。浅色 1280 是选好后的状态。
3模式卡紧凑：3 张一行，标题 14px + 一句 12px，选中卡 = 强调线 + 浅琥珀底；原来是整块带 11px 说明的长卡。
4低频选项默认折叠成一行摘要（译成什么语言 / 原文小字 / 跳过规则），首屏不需要滚动就能开始翻译；原三层长卡（1 翻译哪里 / 2 模式 / 页签）压成 3 块。
5右侧预览在没有目标时是空态而不是空白；900 宽预览移到下方。
