防回退：lint 规则

// stylelint：.vue 的 <style> 里禁止 hex / rgb(a) / hsl(a) 字面量
"color-no-hex": true,
"declaration-property-value-disallowed-list": { "/^(color|background|border|fill|stroke|box-shadow)/": ["/rgba?\(/", "/hsla?\(/"] }
// 例外只允许 theme.css、skin.css 与白名单（色相环、PDF 纸张）

原则

界面色全部走 --cc-*；内容色（色相环、PDF 纸张、缩略图蒙层）单独命名，不借用语义令牌。
悬浮窗、截图浮层这类“固定深色”窗口：在窗口根元素重定义令牌，不在每条规则里写色。
直接复制 theme.css 里的 hex 到组件里（WriteApp 现状）：改一次主题要改两处。
