一个视图（卡片 / 对话框 / 行）最多一个主按钮；其余降为次按钮或文字按钮。
按钮文字是动词：“添加订阅”“重试”“检测模型”。不要“确定 / 提交”。
禁用的按钮必须能看出原因：旁边一行说明，或悬停提示（见工具箱首页）。
加载中保持按钮宽度不变，图标换成转圈，并忽略再次点击。
不用琥珀色文字当“可点”，行内动作要么是 CcButton 文字型，要么是 CcLink。
纯文字、没有悬停底色的“伪按钮”（现有 .pz-link / .lnk / .mi / .ab）。

实现：CcButton.vue，props: kind=primary|secondary|text|danger · size=s|m|l · icon · loading · disabledReason。内部基于 el-button，用 --cc-* 覆盖。

深色
浅色

使用规则

2 到 4 项，每项 ≤ 6 个字；放不下就换 CcSelect。
选中 = 卡片底 + 强调色字 + 1px 强调线；不用整块琥珀填充（那是主按钮的外观）。
禁用项保留位置、文字变淡，并带提示原因。
页面切换用 tab，不用 segmented；segmented 只切“同一块内容的视图 / 模式”。
三套并存的实现（el-radio-button / 自绘 .seg / 自绘 .tabs）。

替换

  • 3 套实现合一：CcSegmented.vue，v-model + options。
  • 设置页排布、主题、取景方式、预览档位等 40+ 处全部走它。

用链接触发保存、删除这类动作，用 CcButton 文字型。

使用规则

一律用 CcSelect，替换写作窗里的原生 <select>：高度 36 / 28，圆角 8，菜单 sh-2。
超过 8 项出现搜索框；选中项左侧有勾。
宽度跟着所在字段行：S 120 · M 180 · L 260 · 通栏。同一张卡里同类控件等宽对齐。
键盘：Enter/空格展开，上下选择，Esc 关闭；焦点环见令牌。
