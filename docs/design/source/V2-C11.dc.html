页面切换审计 维度·动效与反馈

  • 侧栏不动，只切换内容区。
  • 新内容 opacity 0→1 + translateY(4px→0)，--cc-dur-slow 320ms，--cc-ease-out。
  • 旧内容不做退出动画（直接替换），避免两页叠在一起。
  • 数据没到时先显示骨架，不显示空状态。

减弱动效说明审计 维度·动效与反馈

动效默认prefers-reduced-motion: reduce
页面切换淡入 + 上移 4px，320ms只淡入，100ms，无位移
列表行进出淡入/收起，200ms直接出现 / 消失
骨架光带1.4s 循环静态底色，不流动
转圈（加载中）0.8s 旋转保留旋转（它传达“还在进行”）；或换成“加载中…”文字
开关、展开、菜单200ms 位移/淡入去掉位移，只保留颜色变化
完成高亮底色闪一下底色保持 1 秒后退回，无过渡
@media (prefers-reduced-motion: reduce) {
  :root { --cc-dur-fast: 0.01ms; --cc-dur-base: 0.01ms; --cc-dur-slow: 100ms; }
  .cc-skeleton { animation: none; }
}

保存反馈（与自动保存一致）审计 #1

正在保存…已自动保存保存失败 · 重试
  • 顶部状态胶囊三态：保存中 → 已自动保存（3 秒后淡成灰字）→ 失败（常驻，带重试）。
  • 删掉所有“改完点保存才生效”文案。需要保存按钮的编辑（新建服务、对话框）按钮文字是动作，不叫“保存设置”。
