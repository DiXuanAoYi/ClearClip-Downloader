# 媒体库、工具箱与 AI

## 媒体库

“媒体库 → 已下载”是下载下来的所有文件，支持列表 / 网格两种视图，上千条也不卡。

- **整理**：给每个作品加标签、收藏、打分（0–5 星）、写备注；按平台、类型、时间、评分、标签、作者、是否收藏筛选；按最近下载、大小、评分排序。多选后可批量加 / 去标签、收藏、删除、移入[保险箱](security-and-privacy.md)。
- **导入已有文件**：选一个文件夹（可含子文件夹），把里面已有的视频、音频、图片登记进媒体库；和视频同名的字幕会一起登记。已经在库里的文件会跳过；视频时长和封面会在后台补全。
- **删除**：默认先放进回收站（下载目录里的隐藏文件夹 `.ClearClip-Trash`），可以还原，超过保留天数（默认 30，0 表示不自动清空）在启动时永久删除。也可以只删记录、保留文件。
- **整理文件夹**：按模板（默认 `{platform}/{author}`，变量有 `{platform} {author} {year} {month} {day} {date} {kind}`）把已下载的文件移到子目录，同一个作品的字幕、封面一起移动，先预览再执行，目标已有同名文件的会跳过。
- **统计与清理**：占用空间按平台、作者（最多的 15 位）、月份统计，列出最大的文件；清理“文件已经不在磁盘上”的记录。
- **重复文件**：“内容完全相同”按文件头尾和大小的快速哈希找；“画面相似”会在每个视频的 3 个位置各取一帧比较感知哈希，能找出重新编码、不同清晰度的同一个视频（第一次扫描较慢，结果缓存）。每组默认保留最大的一个，勾选其余的删除。
- **字幕搜索**：在所有已下载的 SRT / VTT / ASS 字幕里搜一句话（新下载或导入的字幕自动建立索引，弹幕不参与），点“播放”直接用内置播放器跳到说这句话的位置。
- **预览图与镜头**：给视频均匀取 12 帧拼成一张预览图；“镜头检测”按灵敏度找镜头切换点，可以不重新编码地把每个镜头切成一个文件（起点落在最近的关键帧，可能有零点几秒偏差），保存在视频旁边的“镜头”文件夹。
- **导出清单**：全部记录导出 CSV（Excel 能直接打开）或 JSON。
- **备份与还原**：备份包含媒体库记录、标签、评分、订阅、直播间、解析历史、收到的链接和设置；**不包含**下载的文件本身、登录 Cookie、手机配对令牌和密钥（换电脑后需要重新登录、重新配对）。还原前会保留一份 `.before-restore` 副本，重启清影后生效。

### 内置播放器

媒体库每一行的“播放”（或双击）打开内置播放器：同一文件夹里文件名以视频名开头的字幕（`视频.zh-Hans.srt`、`视频.en.vtt` 等）自动出现在字幕下拉框里，右侧是整份字幕的列表，点一行跳到对应时间，当前这句会高亮；可调 0.5–2 倍速，空格暂停、左右键快退快进 5 秒。

播放器用的是系统自带的网页内核解码：H.264 / AAC 的 MP4 一般都能放，Linux 上需要系统装了 GStreamer 的对应解码插件；mkv / flv / HEVC / 部分 ts 可能放不了，这时界面会显示错误码，并提供“用系统播放器打开”和“用工具箱转成 MP4”。弹幕没有在播放器里渲染，需要的话下载时选“烧录进画面”。

视频通过只监听 `127.0.0.1` 的本机服务提供（支持 Range，可以拖动进度条），不经过网络。

## 工具箱

“工具箱”里所有处理都在本机完成，会生成**新文件**并登记到媒体库，不会修改原文件。大部分需要 ffmpeg（“设置 → 组件”里安装）。进度显示在页面下方，可以取消。

**视频与音频**

| 工具 | 说明 |
| --- | --- |
| 压缩视频 | 重新编码缩小体积，质量分“体积最小 / 均衡 / 画质优先”，可限制最高分辨率 |
| 转 GIF | 截取一段做成动图，可设宽度和帧率 |
| 竖屏转横屏 | 竖屏视频放进 16:9 画面，两侧用模糊背景或黑边补齐 |
| 倍速 | 加快或放慢，音调保持不变 |
| 响度标准化 | 把音量调到统一水平（目标 LUFS，-16 适合手机和网页，-14 是流媒体标准，-23 是广播标准），画面不重新编码 |
| 旋转 / 翻转 | 顺时针、逆时针 90°、180°、水平 / 垂直翻转 |
| 拼接 | 把多个文件首尾相接；先尝试直接拼接，尺寸不同或失败时自动重新编码 |
| 截图 | 截某一帧，或每隔几秒截一张 |
| 转换格式 | 转封装（不重新编码）、转 MP4 / MKV、提取音频（MP3 / M4A / Opus / FLAC / WAV）、去除音轨 |
| 裁剪片段 | 只保留一个时间段；默认不重新编码，可选“精确剪切” |
| 写入章节 | 把章节写进视频，播放器进度条上就会出现章节 |
| 视频规整 | 把录屏、直播录制、平台成片统一成同一规格（帧率、HDR、色彩、黑边、响度、LUT、防抖等），见[视频规整](video-normalize.md) |
| 剪辑 | 时间线剪辑：多段视频 / 图片排列、裁剪、分割、变速、转场、文字、配乐，主轨上可叠加多条视频 / 图片 / GIF（画中画、贴纸），实时预览后导出；还能框出镜头里的运动物体并持续追踪，让马赛克、模糊、局部调色、取景跟着它走，见[剪辑](video-edit.md) |

**字幕**

偏移时间轴、帧率换算（例如 23.976 → 25）、两点校准（开头对得上、越往后越不同步）、合并双语（第二种语言显示在下面）、整理（去掉 HTML 和样式标记、去掉 [音乐]（笑）这类说明）、SRT / VTT / ASS 互相转换（ASS 为默认样式，原样式会丢失）、B站弹幕 XML 转 ASS。

**音频标签**：给 MP3、M4A、FLAC 写入标题、艺术家、专辑和封面（只有 MP3、M4A、FLAC、MP4 支持写封面），保存为新文件，不重新编码。

**弹幕样式**：“设置 → 解析 → 字幕与弹幕”里可调弹幕的字体、字号、不透明度、滚动时间和占画面高度，转换和烧录时都会用。

### 下载时的清晰度选择

- **大小上限**（“设置 → 解析”）：默认选中的格式预估超过上限时，改选不超过的最高清晰度；0 表示不限。网站没给出大小时按码率和时长估算。
- **失败自动降级**（默认开）：因为网络、文件损坏等原因下载失败时，自动改用低一档的清晰度重新下载，最多 3 次。

## AI

“设置 → AI”里配置。所有功能都是可选的，没配置时不影响其它功能。

| 功能 | 做什么 |
| --- | --- |
| 语音转文字 | 把视频 / 音频里的说话内容转成 SRT 字幕，保存在文件旁边，并登记到媒体库、加入字幕搜索。两种引擎：在线接口（兼容 OpenAI 的 `/audio/transcriptions`；音频先在本机转成小体积的单声道再分段上传，按音频时长计费）或本机的 whisper.cpp（填 `whisper-cli` 和 ggml 模型文件的位置，全程不联网） |
| 翻译字幕 | 用大模型把字幕翻成你设置的语言，可以保留原文做成双语（原文在上、译文在下）；每次请求的条数可调，模型漏条时会自动拆小重试；作品里已有目标语言的字幕就不再翻译 |
| 摘要与章节 | 读字幕生成内容摘要、要点和带时间的章节（Markdown 保存在字幕旁边），章节可以复制到视频简介，也可以用“写入章节”写进视频文件 |
| 自动执行 | 可选：下载到的字幕不是目标语言时自动翻译；下载的视频没有字幕时自动转写（隐私模式下不会运行） |

大模型接口用兼容 OpenAI 的地址（OpenAI、DeepSeek、通义千问、月之暗面、智谱，或本机 Ollama 都可以）。**字幕文字会发送到你填写的服务商**；用本机 Ollama 则完全不出本机。密钥加密保存在本机，不写进设置文件，也不进入备份。“省流量模式”开启时不会自动调用 AI。
