# 视频摘要（扩展 1.10）

在视频页面里打开侧栏面板，读取字幕，让清影用**你自己设置的大模型**生成摘要、章节、思维导图、问答和学习卡片。

## 怎么用

1. 清影 → 设置 → **AI** 填好对话模型（接口地址、密钥、模型）。清影 → 设置 → 手机与浏览器扩展 里开启服务，并在扩展里填好端口和访问令牌（和发送链接用的是同一个）。
2. 打开 YouTube / 哔哩哔哩 / 其他带字幕的视频页面，点扩展图标里的“视频摘要 / 总结”，或按 **Alt+Shift+S**，或在页面上右键 → “视频摘要 / 总结…”。再点一次（或点面板的 ✕）关闭。
3. 没有视频的网页也能用：选中一段文字右键“总结选中的文字…”，或直接打开面板，会读取文章正文。

## 面板里有什么

| 标签 | 内容 |
|---|---|
| 摘要 | 总结 + 要点 + 关键词；风格：标准 / 简短 / 详细 / 通俗 / 学习笔记；输出语言可改；要点里的时间可点 |
| 章节 | 优先用 AI 章节；没有就用视频简介里写的章节；播放时跟随高亮，点击跳转 |
| 文稿 | 带时间的完整文稿；搜索（命中词高亮，↑↓ 逐处跳转，`/` 聚焦）；跟随播放自动滚动（手动翻走后出现“回到当前句”）；翻译成你要的语言（双语对照，可隐藏）；导出 .srt / .txt / 复制 |
| 导图 | 生成层级大纲并画成思维导图；保存 SVG / PNG；复制 Markdown 大纲 |
| 问答 | 针对视频提问，只从文稿里找答案；回答里的 `[m:ss]` 可点，直接跳到那一刻；保留最近几轮上下文 |
| 笔记 | 播放时按 **n**（或点视频上的“笔记”按钮，可在“更多”里关闭）记下当前这一句，可提前几秒；文稿里选中文字存为笔记（原文，不经 AI）；鼠标移到一行上点 ＋；本视频 / 全部视频、搜索、编辑、**AI 整理**（先预览，再选替换 / 追加 / 不要）、复制文字或带时间的链接；导出笔记 `.md`（时间带跳转链接）和**学习稿**（YAML 头 + 摘要 + 章节 + 金句 + 我的笔记） |
| 更多 | 学习卡片（导出 TSV，可导入 Anki）、金句、改写成小红书文案 / 推文串 / 博客 / 分享邮件 / 会议纪要式笔记、下载 Markdown、存进清影的便签、发到 Obsidian、换字幕轨、导入 .srt / .vtt / .txt、粘贴文字稿 |

## 文稿从哪来

| 来源 | 做法 |
|---|---|
| YouTube | 读取当前页面的字幕轨（人工字幕优先，再按你的语言偏好选；多条字幕轨可在“更多”里切换），同时读取简介里的章节 |
| 哔哩哔哩 | 通过站内接口读取 CC 字幕（用你已登录的浏览器身份）；AI 字幕通常要登录后才会返回 |
| 其他网站的播放器 | 读取 `<video>` 的字幕轨（`<track>`） |
| 手动 | 导入 .srt / .vtt / .txt，或粘贴文字稿 |
| 没有视频的网页 | 选中的文字，或正文 |
| 页面里读不到字幕 | 读取顺序固定：① 页面上的在线字幕（YouTube 依次试 json3 / vtt / 原始 XML，字幕地址返回空内容时不再报 JSON 错误）→ ② 你以前为这个视频导入 / 粘贴并“记住”的本地字幕（只在在线字幕读不到时才用，在线的永远优先）→ ③ 让清影用 yt-dlp 从网站取在线字幕（`kind: "subtitles"`，快、不花钱，默认开）→ ④ 取音频转写（默认需要点按钮，可在“更多”里勾选自动）。本地字幕按视频编号（YouTube / B 站 BV 号 + 分 P）保存在扩展本地，最多 40 条、约 4 MB，可随时“忘记” |
| 没有字幕的视频 | 面板提供“用清影转写（语音识别）”：清影用 yt-dlp 只取这个视频的音频，再用“设置 → AI”里配好的语音转文字（本机 whisper.cpp 或兼容 OpenAI 的接口）转成带时间的文稿，清影会先尝试取网站自带的在线字幕，没有才取音频转写，随后和有字幕的视频一样总结。进度显示在面板里，可取消；清影的任务列表里也看得到。转写结果会缓存，同一个视频不用再转 |

## 数据流与隐私

```
网页里的字幕 ──扩展面板──▶ 扩展后台 ──127.0.0.1（X-Token）──▶ 清影 ──你配置的大模型接口
```

- 字幕在页面里读取，**只发给本机的清影**；扩展自己不联网请求任何第三方。
- 大模型的密钥只在清影里，不进扩展、不进网页。清影把文稿发给哪个模型，由你在“设置 → AI”里决定（可以是本地模型）。
- 内容脚本不能直接访问 `127.0.0.1`（网页是 https 时会被浏览器当作混合内容拦截），所以一律经扩展后台转发。
- 结果缓存在扩展本地（`storage.local`，最多 40 条、约 3 MB，按文稿内容 + 类型 + 风格 + 语言做键），同一视频再开不用再调模型；清除扩展数据即清空。
- **关掉再打开不用重新生成**：每个视频的整份会话（摘要、导图、学习卡片、金句、翻译、问答对话，以及上次停在哪个标签页）都按文稿内容保存在扩展本地（最近 40 个视频、约 2.5 MB）；重开面板自动带出，摘要页会显示“已保存的结果 · N 分钟前生成”。转写 / 在线字幕取到的文稿也会复用，同一个视频不会再去转写。换了摘要风格或输出语言时，对应的结果不带出，需要时再生成。
- **生成到一半关掉**：关闭面板不会取消任务，清影继续在后台生成；25 分钟内重新打开同一个视频，会自动接上（已完成的直接取回）。要取消请点进度条上的“取消”。清影重启或任务超过 30 分钟则需要重新生成。

## 选词、顺句与其他

- **划词解释**：在文稿里选中词句，点“解释”得到 1–3 句话的说明（识别错误的同音字会指出正确写法），可一键记进笔记。
- **顺句**：自动识别的字幕常常没有标点、有同音错字。文稿页点“顺句”，用你的模型补标点、改明显的错字，行数和时间不变，可随时“还原顺句前”。
- **原文 / 译文 / 双语**：翻译后可切换显示。中文字幕默认译成英文，其他语言译成你设的目标语言；译成中文时会在中英文之间留空格、保留品牌名和术语。
- **金句挂在章节下**：提取金句后，“章节”页按时间把金句放进对应章节。
- **提示词**：“更多 → 提示词”可以改摘要、导图、问答、划词解释、顺句、整理笔记、改写的系统提示词（上限 2 万字，`{lang}` 代表输出语言）；留空用内置的。
- **数据**：可备份 / 恢复设置和笔记（不含密钥）、清除摘要缓存、删除全部笔记。笔记只存在浏览器本地（`chrome.storage.local`），不会上传。
- 问答只依据文稿；文稿里找不到时会明说，而不是编；文稿中的“指令”只当作文字。

## 应用端接口

均需访问令牌，只监听本机。

| 接口 | 作用 |
|---|---|
| `GET /api/v1/ai/status` | 是否已设置模型、目标语言、能否转写（`transcribe`）、能否取在线字幕（`subtitles`，需要 yt-dlp）、文稿长度上限（60 万字符） |
| `POST /api/v1/ai/run` 的 `kind: "subtitles"` | 只用 yt-dlp 取网站的在线字幕（人工 / 自动，转成 SRT 后解析），取不到返回空文稿；`kind: "transcribe"` 也是先取字幕、没有才转写，结果里的 `source` 是 `subtitles` 或 `whisper` |
| `POST /api/v1/ai/run` | 提交任务，返回 `{id}`。body：`kind`（summary / mindmap / cards / quotes / ask / translate / rewrite / explain / punctuate / note / refine）、`title`、`lang`、`style`、`format`、`lines[{t,text}]`、`text`、`question`、`history` |
| `GET /api/v1/ai/job?id=` | 轮询：`{state, done, total, result, error}` |
| `POST /api/v1/ai/cancel?id=` | 取消 |

为什么是“提交 + 轮询”：手机服务给每个请求限时 15 秒，而长视频要分段调用模型。请求体上限普通接口 64 KB，`/api/v1/ai/` 放宽到 2 MiB（文稿可能很长）。长文稿按字数切块，分块得到的要点再合并成一次最终总结；章节时间必须来自文稿里出现过的时间。

## 参考与取舍

参考了几类常见的视频摘要工具，取各家功能里最实用的，并把“调用大模型”放在你自己的清影里，而不是依赖第三方服务：

- Glasp 的 YouTube 摘要：摘要 + 带时间的文稿 + 与视频对话 + 导出到笔记软件（[https://glasp.co/youtube-summary](https://glasp.co/youtube-summary?lang=en)）。
- BibiGPT：章节摘要、字幕搜索、翻译、B 站支持、导出 Obsidian / Notion 笔记，以及要点、金句、行动项（[YouTube → Obsidian 笔记](https://bibigpt.co/en/features/youtube-to-obsidian-notes)）。
- NoteGPT：思维导图（PNG / SVG）、对话、B 站支持。
- Eightify：简短摘要、多语言。

以上是各产品自己的介绍页，难免带宣传色彩；这里只借鉴功能思路，没有使用它们的服务或代码。

## 用本机 Ollama

在“设置 → AI”选“本机 Ollama”（地址 `http://localhost:11434/v1`，密钥可以随便填）即可，字幕文字完全不出本机。因为请求是**清影应用**发给 Ollama 的，不是浏览器扩展发的，所以**不需要**设置 `OLLAMA_ORIGINS`（那个只在浏览器页面或扩展直接请求 Ollama 时才需要）。如果“测试接口”返回 403，才需要在启动 Ollama 前设置 `OLLAMA_ORIGINS=*`（macOS：`launchctl setenv OLLAMA_ORIGINS "*"`；Windows：系统环境变量；Linux：systemd 里加 `Environment=OLLAMA_ORIGINS=*`），然后**完全退出并重新启动** Ollama。

## 已知限制

- 摘要质量取决于你配置的模型；字幕本身错得多（自动字幕）时，摘要也会跟着错。
- 没有字幕的视频要先转写才能总结，这一步在你自己的电脑上做：需要装好 yt-dlp、ffmpeg，并在清影里配置语音转文字；本机 whisper.cpp 转写比字幕慢（一小时的视频在普通电脑上可能要十几分钟到更久），云端接口按你的服务商计费。需要登录才能看的视频，要先在清影里同步对应网站的 Cookie。
- YouTube / 哔哩哔哩的页面结构和接口会变，字幕读取可能失效；失效时可以导入字幕文件或粘贴文字稿。**YouTube / 哔哩哔哩的读取逻辑只用保存下来的页面数据和模拟接口测过，没有在真实网站上验证过**（开发环境无法访问）；哔哩哔哩的接口是从页面跨子域请求的，能否成功取决于站点的跨域设置。
- 播放器在 iframe 里（很多嵌入式视频）时，面板只能读取外层页面，找不到那里的视频和字幕。
- 面板固定在页面右侧，宽 400 px；窄窗口下会盖住页面内容。
- 思维导图是按层级大纲自动排版，节点很多时会很大；PNG 导出遇到超大图会失败，请改用 SVG。
- 存进清影的便签默认不限制字数（应用端请求体上限 16 MiB）；可以在扩展设置的“便签”里填一个字数上限，超出的部分会被截掉。
