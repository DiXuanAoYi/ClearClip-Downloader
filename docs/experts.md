# AI 专家

“专家”= 一套翻译策略（提示词），告诉模型某类内容的用词、语气和格式该怎么处理。入口：设置 → AI → AI 专家。

## 用法
- **默认专家**：下拉选择，默认【通用】（不加任何额外要求）。字幕翻译、扩展的网页翻译都会使用。
- **按网站自动选用**：默认专家是【通用】时，按网址匹配专家的“自动选用网站”（写法同术语库：`example.com`、`*.example.com`、带 `*` 的完整网址、`*`）。优先级：自建 > 社区 > 内置。
- **新建 / 复制**：内置专家不能直接改，点“复制”得到自己的一份再改。策略说明最多 4000 字，英文效果最好。
- **导入 / 导出**：JSON（本程序格式）；也可直接导入沉浸式翻译的专家 `.yml`，程序取其中的任务说明，去掉占位符和输入输出示例。
- **社区专家**：从 `immersive-translate/prompts` 的 `plugins/` 按需拉取，列表取自程序内置的文件名清单（不依赖 GitHub 接口，避免限流）。该仓库未声明许可证，所以只在你点“安装”时下载到本机，不随程序分发。

## 与输出格式的关系
清影用 JSON 数组做批量翻译协议（条数、顺序、占位符必须对齐）。专家说明接在这些固定规则**之后**，并明确“输出格式规则优先”，因此不会因为专家的写法破坏解析。沉浸式翻译专家里的 `{{to}}` 会替换成目标语言，其余占位符会去掉。

## 已知限制
- 网页翻译的本地缓存按“引擎 + 语言 + 原文”计，换专家后已缓存的句子仍显示旧译文；需要重翻请在扩展里清空翻译缓存。
- 社区专家的提示词是为沉浸式翻译的格式写的，换到清影后效果可能有差异。
