# 实时音效：播放时统一音量

浏览器扩展给页面里的每个 `<video>` / `<audio>` 接一条 Web Audio 处理链，播放时实时统一不同视频的音量；清影内置播放器共用同一份代码和预设。

```
声音 → 均衡器 → 混响 → [响度测量] → 增益 → 压缩 → 限幅 → 音量放大 → 输出
```

每一环都可以绕过，全部关掉就等于没接这条链。默认只开**响度标准化**和**限幅**；混响、均衡器默认关。

## 响度标准化

- 测量：K 计权（BS.1770 的两级滤波：1681.97 Hz 高频搁架 +4 dB、38.135 Hz 高通）后，每 100 毫秒一块的均方值；取最近 3 秒（短时响度）。低于 -70 LUFS 的块当静音丢掉，再丢掉比平均低 10 LU 的块，所以讲话的停顿不会把响度拉低。有效的块不足 400 毫秒时不调整。
- 增益：目标响度 - 测到的响度，限制在 [-18 dB, 最大增益]；变化小于 0.5 dB 不动，免得来回抖。用 `setTargetAtTime` 平滑：慢 3 秒 / 中 1.5 秒 / 快 0.6 秒；需要降低时快三倍；换视频后的头 3 秒先用 0.25 秒拉到位。
- 测量放在增益之前（开环），所以不会自己追自己；压缩器自带的“补偿增益”（Chromium / WebKit 按曲线在 0 dB 处的衰减算，取 0.6 次方）关不掉，这里算出来后面接反向增益抵消。
- 压缩：强度 0–100 对应阈值 `-12 - 0.24·c` dB、比例 `1 + 0.05·c`、拐点 12 dB；0 = 1:1 不压缩。
- 限幅：阈值 -1.5 dB、比例 20:1、起音 2 毫秒、释放 80 毫秒，只防拉高音量后爆音。

| 预设 | 目标 | 压缩 | 最大增益 | 适合 |
|---|---|---|---|---|
| 温和（默认） | -16 LUFS | 30% | +12 dB | 短视频、网课，保留一点动态 |
| 标准 | -14 LUFS | 40% | +12 dB | 接近 YouTube 和音乐平台，更响更满 |
| 安静 | -18 LUFS | 35% | +10 dB | 办公室、图书馆 |
| 夜间 | -20 LUFS | 70% | +12 dB | 压低爆炸声、抬高对白，同时压低低频 |
| 广播 | -23 LUFS | 20% | +8 dB | 电视、播客的 EBU R128 标准 |

目标 -30～-8 LUFS、压缩 0–100%、最大增益 0–24 dB、速度慢 / 中 / 快都能自己调；改了任意一项就变成“自定义”。

## 混响与均衡器（默认关）

- 混响：`ConvolverNode` + 程序合成的立体声脉冲响应，不需要任何音频文件。做法和工具箱“音效 / 混响”（`audiofx.rs`）一样：左右各一路白噪声，以 1.8 kHz 分成低频和高频，各乘指数衰减（低频 -60 dB 的时间 = 混响时间，高频是它乘“高频保留”），加预延迟，每路能量归一到 1，所以混合 0 dB ≈ 和干声一样响。八个预设（房间、浴室、客厅、教室、录音棚、板式、音乐厅、教堂）与工具箱同一组参数；混合量可调。混响放在响度测量之前，响度控制会把它一并算进去。
- 均衡器：人声增强（和 `audiofx.rs` 同一组：高通 80 Hz、250 Hz -2 dB、3.2 kHz +2.5 dB）、低音增强、高音增强、压低低频。

## 哪些视频不能处理

`createMediaElementSource` 接进去之后**无法撤回**，而跨域且没有 CORS 的媒体、受版权保护（EME）的媒体接进去会变成没有声音。所以先判断，跳过的只提示、不改声音：

| 情况 | 处理 |
|---|---|
| `blob:` / MSE 播放（大多数网站）、同源文件、声明了 CORS 的跨域文件 | 正常处理 |
| 跨域直链且没有 `crossorigin` | 跳过，提示“视频文件来自另一个网站（域名）…” |
| 设置了 `mediaKeys`（DRM） | 跳过，提示“受版权保护” |

提示每个页面最多出现一次，可选“不再提示”；视频上的小按钮显示“音效 未处理”。

另外，没有用户操作过的页面里 `AudioContext` 起不来，这时接进去也会没有声音，所以先确认 `running` 再接，不行就等下一次点击 / 按键再试。每个页面只建一个 `AudioContext`。

## 入口与设置

- 扩展弹窗“音效”页：开关、预设、自定义滑块、混响与均衡器、实时响度表（输入 / 输出 / 增益）、本站关闭、临时关闭本页。
- 视频右下角的“音效”小按钮 → 快捷面板（响度开关、五个预设、混响三档、本站关闭、更多设置）。
- 设置存在 `storage.local.audioCfg`；按网站关闭记在 `siteRules.off.audio`；功能总开关是 `features.audioFx`（设置 → 功能开关，默认开）。
- 倍速面板里的“音量增益”共用这条链（一个视频只能接一次 Web Audio）。
- 清影内置播放器：顶部“音效”“混响”两个选择，设置记在本机 `localStorage`（`cc.player.fx`）。播放器的视频声明了 `crossorigin="anonymous"`，本机媒体服务的响应带 `Access-Control-Allow-Origin: *`（地址里的令牌是随机的）。

## 已知限制

- 测量有约 0.4 秒的反应延迟；换视频时先快速拉到位再放慢。
- 标签页在后台时不测量（计时器被限速），保持当时的增益。
- 单声道视频按左声道算，立体声两路相加（与 BS.1770 一致）。
- Firefox 里 `BiquadFilterNode` 高通的 Q 同样以 dB 计，行为一致；未在 Safari 上测试。
