# 写作浮窗

在任意网页的输入框里改写、检查语法、翻译、加入统计数据。浏览器扩展负责读写输入框和显示界面，文字处理在清影桌面应用里完成，用的是“设置 → AI”里的模型池。

## 怎么用

1. 点进输入框（文本框、搜索框、富文本编辑器都可以），右下角出现带字数的小浮标。也可以按 **Alt+J**。
2. 选“处理范围”（有选中文字时默认处理选中的，否则处理全文）。
3. 选动作，再按需选长度、正式程度、格式、语气，或在“特别要求”里写一句话，点“生成”。
4. 看差异：绿色是新增，红色删除线是被去掉的；点任意一处可以放弃或重新采用这处改动。
5. 点“替换选中 / 替换原文 / 插入到光标处”，或复制。替换后 Ctrl+Z 可撤销。

## 动作与修饰

| 类别 | 内容 |
| --- | --- |
| 基础 | 改写它、语法检查、翻译、加入统计数据 |
| 改写风格 | 添加细节、增加幽默、使其礼貌、去除专业术语、更多信息、更引人入胜、更有细节、更有说服力、更有歉意、使其真诚、使其简洁、继续写作、缩短它、优化它、总结 |
| 长度 | 自动、短、中等、长 |
| 正式程度 | 自动、随意、中立、正式 |
| 格式 | 自动、电子邮件、消息、评论、段落、文章、博客文章、想法、大纲、推特、Reddit、脸书、领英，以及自己添加的 |
| 语气 | 自动、热情的、幽默的、关心的、谦逊的、乐观的、有同理心的、坦率的、真诚的，以及自己添加的 |

一个动作加四组修饰会合成一条提示词，一次调用完成。

## 加入统计数据

分两步，数字不由模型生成：

1. 模型只负责从固定的指标目录（28 个世界银行指标，如人口、GDP、人均 GDP、互联网使用率、预期寿命）里选出与你文字相关的指标和国家，清影到世界银行开放数据接口查询。
2. 列出数值、年份和原始链接，你勾选后，模型只负责把这些数据自然地写进文字，数字和出处原样保留。

查不到或指标不在目录里时会如实说明，不会编造。目前只接入世界银行，没有直接接入联合国等其他来源。

## 护栏

- 原文里的网址、邮箱、@提及、#话题、数字，结果里缺失或被改动时在结果上方提示。
- 结果长度与原文相差过大（约 4 倍以上或 1/4 以下）时提示。
- 语法检查的位置对不上原文时，该条建议被丢弃，不会误改。
- 密码、支付、验证码、过小的输入框，以及输入法正在输入时，不显示浮标。

## 设置

扩展弹窗 → 设置 → “写作浮窗”：出现方式（浮标 / 只用快捷键）、模型（本地优先 / 只本地 / 只云端）、候选数量、空输入框是否显示、点动作直接生成、不显示浮标的网站。功能总开关在“功能开关”里。

## 隐私

文字只发给本机清影，由清影调用你配置的模型；选“只用本地模型”则不会离开你的电脑。统计数据查询只向世界银行发送指标代码和国家代码。历史记录（最近 50 条）只存在浏览器本地。

## 其他程序里（桌面端，Windows）

- **全局快捷键**（默认 Ctrl+Alt+J，可在“设置 → 写作”改或留空停用）：在任何程序里选中文字后按它，弹出写作窗。清影先等快捷键松开，再模拟一次 Ctrl+C 取词，靠“剪贴板序号有没有变”判断是否真的选中了文字；取完把原来的剪贴板文字放回去。剪贴板里是图片或文件时不去动它，改为让你手动粘贴。点“替换原文”时，清影切回原来的窗口模拟 Ctrl+V，再还原剪贴板；原窗口没了就只复制。
- **小浮标**：在其他程序里点进输入框时，输入框右下角出现一个很小的圆形浮标（不抢焦点、不进任务栏和 Alt+Tab），点一下等同于按快捷键。靠 Windows UI Automation 的焦点事件判断：只在单行 / 多行编辑框里出现；密码框、名称里带“密码 / 验证码 / 银行卡”等词的框、只读框、小于 200×28 的框、全屏程序、清影自己的窗口不出现；不会在没有“可写值”接口的文档（网页正文、只读文档）里冒出来。12 秒没人理自己收起。
- **托盘**：写作浮标“暂停 1 小时”、“不在上一个程序里出现”；设置里可编辑不出现的程序名单，也可以整体关闭浮标。
- **与扩展去重**：扩展每 30 秒向本机报到一次并带上浏览器系列（Chrome / Edge / Firefox / Opera），对应浏览器窗口里桌面端不出浮标；扩展没装、被关掉、清影没连上时，桌面端会接手。浏览器自带页面（设置页、新标签页）和 PDF 查看器扩展管不到，所以扩展报到期间这些页面里也不会出桌面浮标，只能用快捷键。

## 回复、风格、听写、场景

- **回复助手**：选“回复”，上面放收到的消息，“额外要求”里写你想表达的意思（例如“周五可以，改到下午”），生成一条回复；语言默认跟收到的消息一致。
- **个人风格**：设置 → 写作 → “我的写作风格”写一两句话（如“口语化，短句，少用感叹号”），会并进每次改写（桌面和扩展都生效）。也可以粘贴 1–3 段自己写的文字，让模型总结出风格再改；样本文字只发给你选的模型，不保存。
- **听写**：写作窗里点“听写”说一段话，用的是“设置 → AI → 语音转文字”里已有的本机 whisper.cpp 或云端接口，转成文字追加到输入框。需要麦克风权限和 ffmpeg。
- **中文场景**：小红书、微博、朋友圈、公众号标题、知乎回答、周报、简历描述、客服回复，每个带写法要点，选后会作为“格式”交给模型（桌面写作窗里有）。

## 现状与计划

- 已做：浏览器扩展里的全部功能；Windows 桌面端的全局快捷键、模拟复制粘贴、写作窗、自动浮标、托盘控制、与扩展去重；回复、个人风格、听写、中文场景。
- 没有做：macOS 的自动浮标和取词（需要辅助功能权限和原生接口，目前 macOS 和 Linux 只能先复制文字再按快捷键，不能写回）；扩展里的“回复”和场景模板；输入框内的语法下划线标注；联合国等世界银行以外的统计数据来源。
- **未验证**：Windows 桌面端的代码只在 Linux 容器里做了类型检查和纯逻辑单元测试（含 Windows 目标的 `cargo check` / `clippy`），没有在真实 Windows 上运行过——模拟按键、UI Automation 焦点事件、浮标窗口是否真的不抢焦点、各程序的兼容性都需要实机试。世界银行接口在联网环境下的真实返回（解析只用样例数据测过）；各网站富文本编辑器（如 Google Docs 的画布编辑器）不一定能读写；听写在 WebView2 里的麦克风权限弹窗行为。
