# 实时屏幕翻译

翻译别的软件和游戏画面上的文字（仅 Windows）。入口：侧栏【屏幕翻译】、屏幕边上的小悬浮钮、托盘菜单、全局快捷键。

## 管线

画面抓取（区域 / 窗口，GDI）→ 画面指纹变化检测 + 稳定等待 → 识字 → 合并成段落（横排、竖排都认）→ 跳过数字与已是目标语言的文字 → 批量翻译（复用【术语库】【翻译专家】和译文缓存）→ 取原文的底色和字色排版 → 透明、点击穿透、置顶的贴字层。贴字层设了“不被截取”，所以不会把自己的译文再识别一遍。

## 三种模式

| 模式 | 做法 |
|---|---|
| 标准 | 每个文字块被译文盖住，字号按框自动缩小到放得下；画面大幅变化时旧译文立刻撤掉 |
| 字幕 | 只盯字幕区。文字稳定后才翻，相似句去重（≥0.85），一句话分两屏时合并；译文可以盖在原字幕上，也可以进可拖动的悬浮字幕条 |
| 漫画 | 视觉模型整页识别并翻译，给出文字、译文、位置和方向。**竖排译竖排、横排译横排**（中日韩译文正立，字母译文旋转）；先用底色擦掉原字；翻页自动清除 |

## 识字方式

- Windows 自带（默认）：快，不用下载；只能识别 Windows 已安装的语言。
- 增强识字组件：PaddleOCR PP-OCRv4（检测 + 识别，ONNX，本机推理），中英数字，竖排也认。设置里一键下载，也可手动导入模型文件。
- 云端识字服务：OCR.space / 百度智能云 / Google Cloud Vision，自带密钥，密钥只存在本机设置。
- 视觉模型：用“设置 → AI”里的视觉模型直接看图。

## 系统声音实时字幕

抓取电脑正在播放的声音（WASAPI 环回，不需要“立体声混音”），按说话停顿切句，用本机 SenseVoice 或云端语音识别转写，翻译后进悬浮字幕条。设置里可选听的语言、是否双语。

## 按程序记住 / 翻译历史

框选过的程序会记下模式、识字方式、区域，下次它在前台时自动沿用。翻译历史只存在本机（`live_history.jsonl`），可关闭、清空。

## 隐私

- 标准 / 字幕模式默认不上传图片：系统识字和增强识字都在本机；只有你选“云端识字”或“视觉模型”时才会把画面发给对应服务。
- 漫画模式默认走视觉模型，首次使用会弹一次上传提示，确认后记住。
- 云端服务的密钥保存在本机设置里。

## 已知限制

- 独占全屏的游戏，系统截不到画面；请改成“无边框窗口”或“窗口化”。
- “不被截取”依赖 Windows 10 2004 及以上；更早的系统上，贴字层可能被截进画面里造成反复翻译。
- 系统自带识字要装对应的语言包（Windows 设置 → 时间和语言 → 语言和区域）。
- 增强识字的模型下载地址来自第三方发布页，地址失效时请用“手动导入”。
- 目前只在纯逻辑层和跨平台编译上做了自动检查，Windows 上的抓屏、贴字层、环回采集需要在真机上确认。
