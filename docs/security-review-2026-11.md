## 确认没问题的点

- 局域网服务绑定 `0.0.0.0` 是设计（手机要连），所有有意义的接口都要令牌：令牌 32 位随机，用常量时间比较（`ct_eq`），可在设置里重置。
- 令牌不对的请求先过限频（`rate_ok`），再谈正文；未授权的上传 / 下载直接 403，不读正文。已授权的长连接（上传 / 下载）不进内存。
- 请求体按路径和是否授权设了上限（`body_limit`）；每个小请求有总时限。
- 本机媒体服务只绑 `127.0.0.1`，只接受发往 `127.0.0.1:端口` 的请求（挡 DNS 重绑定），按随机令牌取文件，`/etc/passwd` 这类路径返回 404（有测试）。

## 观察到、但不算问题的

- 手机页的令牌放在地址的 `?t=` 里（扫码方便）。局域网内、令牌可重置，风险低；如果以后要给不受信任的网络用，应改成只用 `X-Token` 头。
- 媒体服务的响应带 `Access-Control-Allow-Origin: *`。它只绑本机、地址里有随机令牌，所以不暴露任何东西；记在这里是因为改动这个服务时容易忘。
