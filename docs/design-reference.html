清影界面设计

冷钢深空 + 镜头琥珀（1.16 起）。下面是全部页面的设计稿：解析、下载队列、订阅、直播、屏幕翻译、媒体库、文件翻译、生词与摘录、工具箱与剪辑、浮层、设置的 13 个分类，以及清影写作、浏览器扩展（弹窗、设置、页面内浮层）、手机互传和各个小窗口。点图片看大图。

设计稿的源文件在 docs/design/source/（Claude 设计画布的 .dc.html 和 clearclip.css，canvas.json 是画布布局），生成这些页面的脚本在 docs/design/gen/，图片是用 Chromium 渲染的深色版本。程序里的实现见 desktop/src/styles/theme.css（令牌）和 skin.css（控件和共用版式）。

字体

标题和数字用 Chakra Petch，等宽（路径、速度、快捷键）用 JetBrains Mono，正文用系统中文字体（微软雅黑 / 苹方 / Noto Sans SC）。前两个字体随程序打包（只含拉丁字符子集）。

版式规则

  • 面板：实色底 + 1px 细线 + 圆角 14px，左上和右下各一个琥珀色角标。
  • 左侧固定 88px 导航栏：图标在上、文字在下，设置放在最下面。
  • 页面外框：上下 22px、左右 28px，区块间距 18px；主体 + 右侧粘性方案栏（宽 340–372px）。
  • 设置行：名字和小字说明在左，控件在右，行与行之间一条细线。
  • 分段选择、开关、标签页：选中一律是“琥珀字 + 琥珀描边 / 下划线”。
